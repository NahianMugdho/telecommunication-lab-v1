Cellular Topic 10: Circuit Switching থেকে Packet Core: EPC ও 5GC

Theory • সহজ সারাংশ + বিস্তারিত নোট

2G/3G-তে voice ও data-র জন্য আলাদা core ছিল (CS ও PS domain)। 4G-তে EPC (Evolved Packet Core) এসে সবকিছু এক IP-ভিত্তিক core-এ আনে, আর 5G-তে 5GC আরও সফটওয়্যার-ভিত্তিক, cloud-native ও সেবা-কেন্দ্রিক হয়েছে।

EPC-র নোড (4G)

নোড কাজ
MME Control plane: attach, authentication, mobility, paging, bearer সেটআপ
S-GW User plane: eNodeB-র মধ্যে handover-এ anchor, packet forwarding
P-GW ইন্টারনেট গেটওয়ে, IP ঠিকানা বরাদ্দ, QoS/policy প্রয়োগ, charging
HSS সাবস্ক্রাইবার ডেটাবেস ও authentication ভেক্টর
PCRF নীতি ও চার্জিং নিয়ম নির্ধারণ

EPC ইন্টারফেস: S1-MME (eNodeB–MME), S1-U (eNodeB–S-GW), S11 (MME–S-GW), S5/S8 (S-GW–P-GW), S6a (MME–HSS, Diameter), SGi (P-GW–ইন্টারনেট), Gx (P-GW–PCRF)।

5GC-র নোড (Network Function)

NF কাজ EPC-র সমতুল্য
AMF Access ও mobility, registration, NAS signalling MME-র অংশ
SMF Session ব্যবস্থাপনা, IP বরাদ্দ, UPF নিয়ন্ত্রণ MME, S-GW ও P-GW-র control অংশ
UPF User plane, packet forwarding, QoS S-GW ও P-GW-র user অংশ
UDM/UDR সাবস্ক্রাইবার ডেটা ও তার সংরক্ষণ HSS
AUSF Authentication সার্ভার HSS-র authentication অংশ
PCF নীতি নিয়ন্ত্রণ PCRF
NRF NF আবিষ্কার ও নিবন্ধন (সেবা তালিকা) নতুন
NSSF Slice নির্বাচন নতুন
NEF বাইরের অ্যাপের কাছে সক্ষমতা প্রকাশ নতুন

5GC-র মূল পরিবর্তন

  • Service-Based Architecture (SBA): NF-গুলো একে অপরকে HTTP/2 ভিত্তিক REST API-তে সেবা দেয় (JSON ডেটা); EPC-র Diameter ও GTP-C-র বদলে।

  • CUPS (Control and User Plane Separation): control (SMF) ও user plane (UPF) আলাদা, তাই UPF প্রান্তে (edge) বসিয়ে latency কমানো যায়।

  • Cloud-native: container ও microservice, স্বয়ংক্রিয় স্কেলিং।

  • Slicing ও MEC সহায়তা বিল্ট-ইন।

  • 5G ইন্টারফেস: N1 (UE–AMF), N2 (gNB–AMF), N3 (gNB–UPF), N4 (SMF–UPF), N6 (UPF–Data Network)।

NSA বনাম SA

  • Non-Standalone (NSA): 5G রেডিও (gNB) চলে বিদ্যমান 4G EPC-র উপর, 4G সিগন্যালিংয়ের সাহায্যে (EN-DC, Option 3x)। দ্রুত চালুযোগ্য।

  • Standalone (SA): 5G রেডিও ও 5GC সম্পূর্ণ আলাদা (Option 2); slicing, URLLC ও পূর্ণ 5G সুবিধা এতেই সম্ভব।

সম্ভাব্য MCQ

  • EPC-তে MME-র কাজ কী? → Control plane: mobility ও attach ব্যবস্থাপনা

  • 5G-তে user plane প্যাকেট ফরোয়ার্ড করে কোন NF? → UPF

  • 5GC-তে HSS-এর সমতুল্য কী? → UDM (সাথে AUSF, UDR)

  • 5GC-র NF-গুলো কোন প্রোটোকলে যোগাযোগ করে? → HTTP/2 (REST)

  • gNB ও AMF-এর মধ্যে ইন্টারফেস? → N2

বিস্তারিত নোট

১০.১ কেন বিবর্তন?

2G/3G-তে দুটি আলাদা core ছিল: ভয়েসের জন্য CS (MSC) ও ডেটার জন্য PS (SGSN/GGSN)। ডেটা বিস্ফোরণে এই কাঠামো জটিল ও ধীর হয়ে পড়ে। 3GPP Release 8 (২০০৮)-এর SAE (System Architecture Evolution) পুরো core-কে এক flat, all-IP কাঠামোয় আনে; নাম EPC (Evolved Packet Core); রেডিও অংশ LTE/E-UTRAN; মিলিতভাবে EPS (Evolved Packet System)। এখানে CS domain নেই, ভয়েস চলে IP-তে (VoLTE)। এরপর Release 15 (২০১৮) থেকে 5G ও 5GC।

লক্ষ্য EPC-তে সমাধান
কম latency কম নোড (flat); RNC বিলুপ্ত, eNodeB নিজে radio control করে
বেশি গতি OFDMA, MIMO, সব IP
সরল কাঠামো CS ও PS একত্রিত, ভয়েস IMS-এ
নমনীয়তা control (MME) ও user plane (S/P-GW) আলাদা নোড

১০.২ E-UTRAN: eNodeB-র কাজ

eNodeB (eNB) 3G-র NodeB ও RNC-র কাজ একত্রে করে: radio resource management, dynamic scheduling (uplink/downlink), admission control, header compression ও ciphering (PDCP), mobility measurement ও handover সিদ্ধান্ত, MME নির্বাচন, interference সমন্বয় (ICIC), paging বিতরণ। eNB-গুলো X2 দিয়ে সরাসরি যুক্ত (handover-এ ডেটা ফরওয়ার্ডিং)।

১০.৩ EPC-র নোড বিস্তারিত

নোড মূল কাজ
MME শুধু control plane। NAS signalling, authentication ও security, attach/detach, tracking area list ব্যবস্থাপনা, paging, S-GW/P-GW নির্বাচন, bearer সেটআপ, handover সমন্বয়, roaming, HSS-এর সাথে যোগাযোগ
S-GW (Serving Gateway) User plane। eNB-এর মধ্যে handover-এ local mobility anchor, 2G/3G-র সাথে mobility anchor, packet routing/forwarding, idle ইউজারের downlink ডেটা বাফার, lawful interception, charging তথ্য
P-GW (PDN Gateway) ইন্টারনেট গেটওয়ে। UE-কে IP ঠিকানা বরাদ্দ, policy ও QoS প্রয়োগ (PCRF-এর নীতিতে), packet filtering, charging, non-3GPP (Wi-Fi) mobility anchor, SGi ইন্টারফেস
HSS সাবস্ক্রাইবার ডেটাবেস ও authentication কেন্দ্র (HLR + AuC-র উত্তরসূরি)
PCRF Policy and Charging Rules Function: QoS নিয়ম ও চার্জিং নীতি
ePDG, ANDSF untrusted Wi-Fi ইন্টিগ্রেশন ও নেটওয়ার্ক বাছাইয়ের নীতি

ইন্টারফেস:

ইন্টারফেস সংযোগ প্রোটোকল
S1-MME eNB–MME S1AP/SCTP
S1-U eNB–S-GW GTP-U
S11 MME–S-GW GTPv2-C
S5/S8 S-GW–P-GW (S5 নিজ নেটওয়ার্কে, S8 roaming-এ) GTP বা PMIP
S6a MME–HSS Diameter
S10 MME–MME GTPv2-C
S3 / S4 MME/S-GW–SGSN (2G/3G interworking) GTP
SGi P-GW–ইন্টারনেট/IMS IP
Gx P-GW–PCRF Diameter

EPS শনাক্তকারী: GUTI = GUMMEI (MCC + MNC + MME Group ID + MME Code) + M-TMSI; TAI = MCC + MNC + TAC; ECGI = MCC + MNC + ECI।

CUPS (Release 14): S-GW ও P-GW-কে আরও control (SGW-C/PGW-C) ও user (SGW-U/PGW-U) ভাগ করা; user plane edge-এ নামানো যায়। এটাই 5G-তে SMF/UPF-এ পূর্ণতা পায়।

১০.৪ 5G Core (5GC): Service-Based Architecture

EPC-তে প্রতিটি নোড নির্দিষ্ট ইন্টারফেসে বাঁধা (point-to-point)। 5GC-তে control plane-এর NF-গুলো সেবা (service) হিসেবে নিজেদের API উন্মুক্ত করে, বাস (bus)-এর মতো; যে কেউ যেকোনো NF-এর সেবা ডাকতে পারে।

মূল বৈশিষ্ট্য:

  • SBA: NF-গুলো HTTP/2 REST API (JSON) দিয়ে যোগাযোগ করে; নামকরণ Namf, Nsmf, Nudm, Npcf, Nnrf ইত্যাদি। নিরাপত্তায় TLS ও OAuth 2.0 টোকেন।

  • NF discovery: NRF একটি রেজিস্ট্রি। NF নিজেকে register করে (NF profile), অন্যরা discover/subscribe করে।

  • Control/User plane পূর্ণ বিভাজন (CUPS): SMF ও UPF আলাদা, N4/PFCP প্রোটোকলে নিয়ন্ত্রণ।

  • Cloud-native: microservice, container, স্বয়ংক্রিয় স্কেলিং।

  • Slicing, MEC, access-agnostic (3GPP ও non-3GPP একই core-এ) বিল্ট-ইন।

NF-এর তালিকা:

NF কাজ EPC-র সমতুল্য
AMF registration, connection, reachability ও mobility ব্যবস্থাপনা; NAS ও N2 সমাপ্তি; security anchor MME-র mobility অংশ
SMF PDU session ব্যবস্থাপনা, UE IP বরাদ্দ, UPF নির্বাচন ও নিয়ন্ত্রণ, QoS প্রয়োগ MME-র session অংশ + S/P-GW-র control
UPF packet routing/forwarding, QoS, usage report, anchor point, ইন্টারনেটে (N6) সংযোগ S-GW-U ও P-GW-U
UDM সাবস্ক্রিপশন ডেটা, authentication credential তৈরি (ARPF), SUCI deconcealment (SIDF) HSS
UDR সাবস্ক্রাইবার ডেটার আসল সংরক্ষণ HSS-এর ডেটাবেস অংশ
AUSF authentication সার্ভার HSS-এর authentication অংশ
PCF নীতি ও QoS নিয়ম PCRF
NRF NF registry ও discovery নতুন
NSSF slice নির্বাচন নতুন
NEF বাইরের অ্যাপের কাছে সক্ষমতা উন্মুক্ত SCEF-এর উত্তরসূরি
AF অ্যাপ্লিকেশন ফাংশন (নীতি প্রভাবিত করে) AF
SCP, SEPP SCP: NF-এর মধ্যে indirect যোগাযোগ; SEPP: roaming-এ দুই নেটওয়ার্কের মধ্যে নিরাপত্তা প্রহরী নতুন
N3IWF untrusted non-3GPP (Wi-Fi) ইন্টিগ্রেশন ePDG

ইন্টারফেস সংযোগ প্রোটোকল

5G শনাক্তকারী: SUPI (স্থায়ী, IMSI-র মতো), SUCI (এনক্রিপ্টেড SUPI, রেডিওতে যায়), 5G-GUTI (অস্থায়ী), GPSI (বাহ্যিক, যেমন ফোন নম্বর), PEI (ডিভাইস, IMEI-র মতো), TAI, NCGI।

১০.৫ EPC বনাম 5GC তুলনা

বিষয় EPC (4G) 5GC (5G)
কাঠামো point-to-point ইন্টারফেস সেবা-ভিত্তিক (SBA)
প্রোটোকল GTP-C, Diameter HTTP/2 + JSON
Control/User আংশিক (CUPS পরে) পূর্ণ বিভাজন (SMF/UPF)
বাস্তবায়ন VNF, VM-কেন্দ্রিক CNF, container

QoS মডেল Bearer (QCI) QoS Flow (5QI)
Session PDN connection PDU session
Mobility ও session MME-তে একত্রে AMF ও SMF-এ আলাদা

১০.৬ 5G deployment: NSA ও SA

  • NSA (Non-Standalone, Option 3x/EN-DC): 5G gNB 4G eNB-এর সাথে dual connectivity-তে; core EPC; control সিগন্যালিং 4G-র মাধ্যমে। দ্রুত চালু করা যায় বিদ্যমান core ব্যবহার করে; কিন্তু slicing ও কম latency-র পূর্ণ সুবিধা নেই।

  • SA (Standalone, Option 2): gNB + 5GC; সম্পূর্ণ 5G সুবিধা (slicing, URLLC, SBA)।

  • অন্যান্য: Option 4, 7 (4G-কে 5GC-তে যুক্ত করা, NGEN-DC)।

  • ভয়েস: VoLTE → VoNR (5G-তে IMS voice); যতদিন VoNR পরিপক্ক নয়, EPS Fallback (5G থেকে 4G-তে নেমে VoLTE)।

  • Interworking: 4G↔︎5G handover N26 ইন্টারফেসে।

১০.৭ অনুশীলন

  1. EPC-তে UE-কে IP ঠিকানা দেয় কোন নোড? → P-GW।

  2. 5GC-তে SMF–UPF প্রোটোকল? → PFCP (N4)।

  3. S1-U কোন প্রোটোকল ব্যবহার করে? → GTP-U।

  4. 5G roaming-এ নিরাপত্তা প্রহরী NF? → SEPP।

  5. 5G-তে 4G-র HSS-এর সমতুল্য কী কী? → UDM, UDR, AUSF।
