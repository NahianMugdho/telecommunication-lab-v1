Topic 10: Circuit Switching থেকে Packet Core: EPC ও 5GCFrom Circuit Switching to Packet Core: EPC and 5GC

Theory • সহজ সারাংশ + বিস্তারিত নোটTheory • short note + detailed note

🧠 সংক্ষেপ নোটShort note

2G/3G-তে ভয়েস ও ডেটার জন্য দুটি আলাদা core ছিল। 4G-র EPC সবকিছু IP packet হিসেবে এক core-এ আনল। 5GC আরও এগিয়ে: প্রতিটি কাজ একটি আলাদা software function, সবাই HTTP/2 দিয়ে কথা বলে।In 2G/3G voice and data had two separate cores. The 4G EPC brought everything into one IP core. The 5GC goes further: every job is a separate software function, all talking over HTTP/2.

  • EPC: MME (control), S-GW, P-GW (data), HSS (ডাটাবেস), PCRF (নিয়ম)।EPC: MME (control), S-GW, P-GW (data), HSS (database), PCRF (rules).
  • 5GC: AMF (access/mobility), SMF (session), UPF (data), UDM/UDR (ডাটাবেস), AUSF (authentication), PCF (policy), NRF, NSSF।5GC: AMF (access/mobility), SMF (session), UPF (data), UDM/UDR (database), AUSF (authentication), PCF (policy), NRF, NSSF.
  • CUPS: control plane ও user plane আলাদা। 4G-তে Sx, 5G-তে N4 (PFCP)।CUPS: control plane and user plane are separate. Sx in 4G, N4 (PFCP) in 5G.
  • SBA / SBI: HTTP/2 + JSON।SBA / SBI: HTTP/2 + JSON.
  • N1 UE–AMF, N2 gNB–AMF, N3 gNB–UPF, N4 SMF–UPF, N6 UPF–Data Network।N1 UE–AMF, N2 gNB–AMF, N3 gNB–UPF, N4 SMF–UPF, N6 UPF–Data Network.
  • SA (Option 2) = gNB + 5GC। NSA (Option 3x) = LTE anchor + EPC।SA (Option 2) = gNB + 5GC. NSA (Option 3x) = LTE anchor + EPC.

🧠 মনে রাখার কৌশল:Memory trick: MME → AMF + SMF (ভাগ হয়ে গেছে); S-GW + P-GW → UPF (একটাতে মিশেছে); HSS → UDM/UDR/AUSF; PCRF → PCF।MME → AMF + SMF (it split); S-GW + P-GW → UPF (they merged); HSS → UDM/UDR/AUSF; PCRF → PCF.
