Topic 9: Packet Switching ও Call ControlPacket Switching and Call Control

Theory • সহজ সারাংশ + বিস্তারিত নোটTheory • short note + detailed note

🧠 সংক্ষেপ নোটShort note

Packet switching-এ ডেটা ছোট packet হয়ে স্বাধীনভাবে গন্তব্যে যায়। আর call control ঠিক করে কে কাকে ডাকছে, কখন কথা শুরু ও শেষ হবে। পুরোনো ফোনে এই কাজ করত SS7, এখন করে SIP।In packet switching data travels as small independent packets. Call control decides who is calling whom and when the call starts and ends. Old phones used SS7 for this; today SIP does it.

  • Packet = header (ঠিকানা, নম্বর) + payload (আসল ডেটা)।Packet = header (address, number) + payload (the real data).
  • Delay: processing + queuing + transmission (L/R) + propagation (d/s)।Delay: processing + queuing + transmission (L/R) + propagation (d/s).
  • Signalling (কে কল করছে) আর media (কথা) আলাদা পথে চলে।Signalling (who is calling) and media (the talk) travel on separate paths.
  • SIP: INVITE → 100 Trying → 180 Ringing → 200 OK → ACK। শেষে BYE। Port 5060।SIP: INVITE → 100 Trying → 180 Ringing → 200 OK → ACK. End with BYE. Port 5060.
  • RTP ভয়েস বহন করে, RTCP মান (jitter, loss) জানায়।RTP carries voice, RTCP reports quality (jitter, loss).
  • VoIP bandwidth: G.711 → IP স্তরে 80 kbps, G.729 → 24 kbps।VoIP bandwidth: G.711 → 80 kbps at IP level, G.729 → 24 kbps.
  • Diameter (port 3868) = AAA ও policy protocol।Diameter (port 3868) = AAA and policy protocol.

🧠 মনে রাখার কৌশল:Memory trick: SIP কলের ক্রম: "ডাক, চেষ্টা, বাজছে, ধরেছে, নিশ্চিত" = INVITE, 100, 180, 200, ACK।SIP call order: "invite, trying, ringing, OK, confirm" = INVITE, 100, 180, 200, ACK.

৯.২ Delay-র হিসাব (সূত্রসহ)9.2 Delay calculations (with formulas)
মোট delayTotal delay
d = dproc + dqueue + dtrans + dprop
proc = header দেখা, queue = লাইনে অপেক্ষা, trans = বিট ঠেলে দেওয়া, prop = তারে ভ্রমণ।proc = reading the header, queue = waiting in line, trans = pushing the bits out, prop = travel in the wire.
Transmission ও Propagation delayTransmission and propagation delay
dtrans = L / R, dprop = d / s
L = packet আকার (bit), R = link গতি (bps), d = দূরত্ব, s = সিগন্যালের গতি (fiber-এ প্রায় 2×10⁸ m/s)।L = packet size (bits), R = link rate (bps), d = distance, s = signal speed (about 2×10⁸ m/s in fiber).
✍ 1500 byte (12,000 bit), 10 Mbps: 12,000 / 10⁷ = 1.2 ms। 2000 km fiber: 2×10⁶ / 2×10⁸ = 10 ms।1500 bytes (12,000 bits) at 10 Mbps: 12,000 / 10⁷ = 1.2 ms. 2000 km of fiber: 2×10⁶ / 2×10⁸ = 10 ms.
৯.৩ VoIP-র bandwidth (সূত্রসহ)9.3 VoIP bandwidth (with formulas)

ভয়েস packet-এর ওপর RTP (12 byte) + UDP (8) + IP (20) = 40 byte header যোগ হয়। তাই IP স্তরে গতি codec-এর গতির চেয়ে বেশি।Each voice packet gets RTP (12 bytes) + UDP (8) + IP (20) = 40 bytes of header. So the IP-level rate is higher than the codec rate.

Payload আকার ও IP bitratePayload size and IP bitrate
payload = codec rate × packet time
IP bitrate = (payload + 40 byte) × 8 / packet time
✍ G.711 (64 kbps, 20 ms): payload = 64,000 × 0.02 / 8 = 160 byte; (160 + 40) × 8 / 0.02 = 80 kbps।
G.729 (8 kbps, 20 ms): payload = 20 byte; (20 + 40) × 8 / 0.02 = 24 kbps।G.711 (64 kbps, 20 ms): payload = 64,000 × 0.02 / 8 = 160 bytes; (160 + 40) × 8 / 0.02 = 80 kbps.
G.729 (8 kbps, 20 ms): payload = 20 bytes; (20 + 40) × 8 / 0.02 = 24 kbps.

⚠ ভুল ধারণা:Common mistake: G.729-এর codec গতি 8 kbps হলেও header মিলিয়ে নেটওয়ার্কে লাগে 24 kbps। header-ই বেশির ভাগ জায়গা নেয়।G.729 is 8 kbps at the codec but needs 24 kbps on the network with headers. Headers take most of the space.
