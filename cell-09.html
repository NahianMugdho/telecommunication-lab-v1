Cellular Topic 9: Packet Switching ও Call Control

Theory • সহজ সারাংশ + বিস্তারিত নোট

Packet switching-এ বার্তা ছোট packet-এ ভেঙে প্রতিটি আলাদাভাবে গন্তব্যে পাঠানো হয়, আর call control হলো কল শুরু, চালু রাখা ও শেষ করার নিয়ন্ত্রণ ও signalling ব্যবস্থা।

Packet switching-এর ধরন

  • Datagram: প্রতিটি packet স্বাধীনভাবে route হয় (IP); ক্রম উল্টে যেতে পারে।

  • Virtual circuit: আগে একটি লজিক্যাল পথ ঠিক হয়, সব packet সেই পথে যায় (X.25, ATM, MPLS-এর লেবেল)।

  • Store-and-forward: রাউটার পুরো packet গ্রহণ করে তারপর পরবর্তী হপে পাঠায়।

  • Transport: TCP (নির্ভরযোগ্য, সংযোগভিত্তিক, ওয়েব/ইমেইল), UDP (দ্রুত, সংযোগহীন, voice/video/স্ট্রিমিং)।

Signalling ও Bearer আলাদা

  • Signalling (control plane): কল সেটআপ, মুছে ফেলা, mobility, বার্তা আদান-প্রদানের তথ্য।

  • Bearer/User plane: আসল voice বা ডেটা।

  • আধুনিক নেটওয়ার্ক out-of-band signalling ব্যবহার করে, অর্থাৎ signalling আলাদা চ্যানেলে চলে।

Circuit-switched নেটওয়ার্কের signalling: SS7

প্রোটোকল কাজ
MTP (1-3) নিচু স্তরের নির্ভরযোগ্য বার্তা পরিবহন
SCCP Routing ও global title translation
ISUP কল সেটআপ ও শেষ করা (সুইচের মধ্যে voice সার্কিট নিয়ন্ত্রণ)
TCAP লেনদেনভিত্তিক বার্তা (ডেটাবেস অনুসন্ধান)
MAP মোবাইল-নির্দিষ্ট: HLR-এর সাথে location update, authentication, SMS

সাধারণ ISUP কল প্রবাহ: IAM (Initial Address Message) → ACM (Address Complete) → ANM (Answer) → REL (Release) → RLC (Release Complete)।

SIP (Session Initiation Protocol)

  • IP নেটওয়ার্কে voice/video সেশন শুরু, পরিবর্তন ও শেষ করার টেক্সটভিত্তিক প্রোটোকল (HTTP-র মতো গঠন); VoLTE ও IMS-এর ভিত্তি। ডিফল্ট port 5060।

  • Methods: REGISTER (অবস্থান নিবন্ধন), INVITE (কল শুরু), ACK (নিশ্চিতকরণ), BYE (কল শেষ), CANCEL (শুরু হওয়া কল বাতিল), OPTIONS।

  • Response কোড: 1xx সাময়িক (180 Ringing), 2xx সফল (200 OK), 3xx পুনর্নির্দেশ, 4xx ক্লায়েন্টের ত্রুটি (404 Not Found), 5xx সার্ভারের ত্রুটি, 6xx সার্বিক ব্যর্থতা।

  • SDP: মিডিয়ার ধরন, codec, port-এর বিবরণ; RTP/RTCP: আসল মিডিয়া ও তার মান-প্রতিবেদন বহন করে।

  • সাধারণ ক্রম: INVITE → 100 Trying → 180 Ringing → 200 OK → ACK → (RTP media) → BYE → 200 OK।

Call control-এর ধাপ (মোবাইল কল)

  1. কলকারী নম্বর ডায়াল করে, নেটওয়ার্কে সংযোগ ও রিসোর্স অনুরোধ।

  2. নেটওয়ার্ক authentication ও কলের অনুমতি যাচাই করে।

  3. গ্রহীতার অবস্থান খুঁজে (paging) তাকে রিং করায়।

  4. গ্রহীতা উত্তর দিলে voice পথ সংযুক্ত (bearer তৈরি)।

  5. কথোপকথন চলাকালীন handover ও QoS পর্যবেক্ষণ।

  6. যেকোনো পক্ষ কাটলে রিসোর্স মুক্ত ও বিলিং রেকর্ড (CDR) তৈরি।

সম্ভাব্য MCQ

  • SIP-এর ডিফল্ট port কত? → 5060

  • SIP-এর কোন method দিয়ে কল শুরু হয়? → INVITE

  • SS7-এ কল সেটআপের জন্য কোন প্রোটোকল? → ISUP

  • SIP-এ "180" কী বোঝায়? → Ringing

  • IP নেটওয়ার্কে real-time voice সাধারণত কোন transport-এ চলে? → UDP (RTP)

বিস্তারিত নোট

৯.১ Packet switching-এর মূল ধারণা

বার্তা ছোট packet-এ ভাঙা হয়; প্রতিটিতে header (ঠিকানা, ক্রম, নিয়ন্ত্রণ তথ্য) ও payload থাকে। রাউটার প্রতিটি packet-এর header দেখে পরের hop ঠিক করে (store-and-forward)।

ধরন কাজের পদ্ধতি উদাহরণ
Datagram প্রতিটি packet স্বাধীন, সংযোগ স্থাপন নেই, ক্রম বদলাতে পারে IP
Virtual circuit আগে লজিক্যাল পথ ঠিক, সব packet সেই পথে, ক্রম বজায় X.25, Frame Relay, ATM, MPLS (label switched path)

সুবিধা: রিসোর্স ভাগাভাগি, bursty ট্রাফিকে দক্ষ, ব্যর্থ লিংক এড়িয়ে পথ বদল। অসুবিধা: delay ও jitter পরিবর্তনশীল, packet হারাতে পারে (তাই QoS দরকার)।

IP header মূল তথ্য: IPv4 header ন্যূনতম 20 বাইট; ক্ষেত্র: version, header length, DSCP/ToS, total length, identification/fragment, TTL (প্রতি hop-এ 1 কমে, 0 হলে packet বাতিল; loop রোধ), protocol (6 = TCP, 17 = UDP, 1 = ICMP), source ও destination ঠিকানা (32 বিট)। IPv6: ঠিকানা 128 বিট, header 40 বাইট।

Transport স্তর:

বিষয় TCP UDP
সংযোগ সংযোগভিত্তিক (3-way handshake: SYN, SYN-ACK, ACK) সংযোগহীন
নির্ভরযোগ্যতা ACK, পুনঃপ্রেরণ, ক্রম, flow ও congestion control নেই
গতি/ওভারহেড বেশি ওভারহেড কম
ব্যবহার ওয়েব, ইমেইল, ফাইল VoIP/RTP, ভিডিও স্ট্রিম, DNS, গেম

QoS-এর মূল ব্যবস্থা: DiffServ (packet-এ DSCP চিহ্ন; voice-এর জন্য EF = DSCP 46), priority queuing, traffic shaping/policing, MPLS (label)। MPLS label 32 বিটের shim header: 20 বিট label, 3 বিট traffic class, 1 বিট bottom-of-stack, 8 বিট TTL।

৯.২ Call Control ও Signalling-এর ধারণা

  • CAS (Channel Associated Signalling): signalling ভয়েসের একই চ্যানেলে বা তার সাথে বাঁধা। পুরনো, সীমিত।

  • CCS (Common Channel Signalling): signalling আলাদা চ্যানেল/নেটওয়ার্কে (SS7)। দ্রুত কল সেটআপ, সমৃদ্ধ সেবা (prepaid, roaming, SMS)।

SS7 স্ট্যাক:

স্তর কাজ
MTP-1/2/3 ভৌত লিংক, নির্ভরযোগ্য বার্তা, রাউটিং (point code)
SCCP অতিরিক্ত রাউটিং (Global Title translation), connectionless/connection-oriented
ISUP PSTN/মোবাইল কলের সার্কিট সেটআপ ও বন্ধ
TCAP ডেটাবেস ও লেনদেন (ট্রানজ্যাকশন)
MAP মোবাইল সেবা: location update, authentication, SMS, handover
INAP/CAP Intelligent Network (prepaid, CAMEL)

ISUP কল প্রবাহ (A থেকে B):

  1. IAM (Initial Address Message): গন্তব্য নম্বরসহ কল শুরু; সার্কিট দখল।

  2. ACM (Address Complete): গন্তব্য পাওয়া গেছে, রিং হচ্ছে (ringback tone)।

  3. ANM (Answer): B ধরেছে; বিলিং শুরু।

  4. কথোপকথন।

  5. REL (Release): যেকোনো পক্ষ কেটেছে।

  6. RLC (Release Complete): সার্কিট মুক্ত।

GSM Mobile-Originated কল:

  1. ফোন Channel Request (RACH) পাঠায় → Immediate Assignment (AGCH) → সিগন্যালিং channel SDCCH।

  2. CM Service Request → Authentication (RAND/SRES) → Ciphering Mode Command।

  3. Setup (গন্তব্য নম্বর) → MSC থেকে Call Proceeding।

  4. Assignment Command → ভয়েস channel (TCH) বরাদ্দ।

  5. B-পক্ষে paging ও ringing → Alerting → B ধরলে Connect → Connect Acknowledge।

  6. কথা শেষে Disconnect → Release → Release Complete; রেডিও channel মুক্ত।

Mobile-Terminated কল: GMSC HLR-কে জিজ্ঞেস করে (SRI) → MSRN পেয়ে ভিজিটেড MSC-তে রাউট → Paging → ফোন সাড়া দেয় (Paging Response) → authentication ও ciphering → Setup → Alerting → Connect।

ISDN/Q.931 বার্তা: SETUP, CALL PROCEEDING, ALERTING, CONNECT, CONNECT ACK, DISCONNECT, RELEASE, RELEASE COMPLETE। (GSM-এর call control এর অনেকটাই এই ধাঁচের।)

৯.৩ SIP (Session Initiation Protocol)

IP নেটওয়ার্কে সেশন (ভয়েস, ভিডিও, মেসেজিং) তৈরি, পরিবর্তন ও শেষ করার টেক্সট-ভিত্তিক প্রোটোকল (RFC 3261); গঠন HTTP-র মতো। ডিফল্ট port 5060 (UDP/TCP), 5061 (TLS)।

SIP উপাদান:

  • UA (User Agent): UAC (অনুরোধকারী) ও UAS (উত্তরদাতা)।

  • Proxy server: অনুরোধ ফরওয়ার্ড করে (routing)। Registrar: REGISTER গ্রহণ করে ইউজারের বর্তমান ঠিকানা (binding) সংরক্ষণ। Redirect server: গন্তব্য জানিয়ে দেয়। B2BUA: দুই পাশে আলাদা সেশন (SBC ও অ্যাপ সার্ভারে)।

Method: REGISTER, INVITE, ACK, BYE, CANCEL, OPTIONS, SUBSCRIBE/NOTIFY, MESSAGE, UPDATE, PRACK, REFER।

Response কোড: 1xx সাময়িক (100 Trying, 180 Ringing, 183 Session Progress), 2xx সফল (200 OK), 3xx পুনর্নির্দেশ, 4xx ক্লায়েন্ট ত্রুটি (401 Unauthorized, 404 Not Found, 486 Busy Here), 5xx সার্ভার ত্রুটি (503 Service Unavailable), 6xx সার্বিক ব্যর্থতা (603 Decline)।

মূল header: Via (পথ), From, To, Call-ID (কল শনাক্ত), CSeq (অনুরোধের ক্রম), Contact (সরাসরি ঠিকানা), Content-Type: application/sdp।

সাধারণ কল প্রবাহ: INVITE (SDP offer) → 100 Trying → 180 Ringing → 200 OK (SDP answer) → ACK → RTP মিডিয়া → BYE → 200 OK।

SDP: মিডিয়ার বিবরণ: v= (version), o= (origin), s= (session), c= (connection ঠিকানা), t= (সময়), m= (media: audio, port, RTP/AVP, payload type), a= (attribute, যেমন codec)। Offer/answer মডেলে codec ও port দর কষাকষি।

RTP/RTCP: RTP header 12 বাইট (sequence number, timestamp, SSRC, payload type)। Payload type: 0 = PCMU (G.711 μ-law), 8 = PCMA (G.711 A-law), 18 = G.729। RTCP মান-প্রতিবেদন (loss, jitter) পাঠায়।

৯.৪ Voice Codec ও VoIP bandwidth

Codec বিটরেট বৈশিষ্ট্য
G.711 64 kbps PCM, মান ভালো, বেশি bandwidth
G.729 8 kbps compressed
AMR-NB 4.75–12.2 kbps 2G/3G ভয়েস (8 kHz)
AMR-WB 6.6–23.85 kbps HD voice (16 kHz)
EVS 5.9–128 kbps VoLTE-র আধুনিক, super-wideband পর্যন্ত

IP-স্তরে bandwidth (20 ms packetization):

প্যাকেট=payload+12(RTP)+8(UDP)+20(IP)50 packet/s

  • G.711: payload 160 বাইট ⇒ প্যাকেট 200 বাইট ⇒ 200 × 8 × 50 = 80 kbps (কোডেকের 64 kbps-এর চেয়ে বেশি)।

  • G.729: payload 20 বাইট ⇒ প্যাকেট 60 বাইট ⇒ 60 × 8 × 50 = 24 kbps।

VoIP মান: একমুখী delay ≤ 150 ms (ITU-T G.114), jitter যতটা সম্ভব কম (jitter buffer দিয়ে সামলানো), packet loss 1%-এর নিচে ভালো। মান মাপা হয় MOS (1–5; 4+ চমৎকার)।

৯.৫ Diameter (4G-তে AAA প্রোটোকল)

RADIUS-এর উত্তরসূরি; TCP/SCTP-এ চলে (port 3868); বার্তা AVP (Attribute-Value Pair) দিয়ে গঠিত। মৌলিক বার্তা: CER/CEA (সংযোগ), DWR/DWA (জীবিত থাকা)। ইন্টারফেস/অ্যাপ্লিকেশন: S6a (MME–HSS: ULR/ULA, AIR/AIA), Gx (P-GW–PCRF), Rx (P-CSCF–PCRF), Cx (CSCF–HSS), Gy (online charging)। DRA (Diameter Routing Agent) বার্তা রাউট করে।

৯.৬ অনুশীলন

  1. G.711 ভয়েস 20 ms packetization-এ IP-স্তরে কত bandwidth? → 80 kbps।

  2. ISUP-তে কল শুরুর বার্তা? → IAM।

  3. SIP-এ 486 কী? → Busy Here।

  4. SIP-এর TLS port? → 5061।

  5. DSCP EF মান কত? → 46 (voice)।
