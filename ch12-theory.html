সহজ ভাষায় বুঝি (Simple Explanation)

Signal-এর তিন রূপান্তর: Shift x(t−t₀): t₀ > 0 হলে signal ডানে সরে (দেরি হয়)। Mirror x(−t): বাম-ডান উল্টে যায়। Scale x(2t): সময়ে সংকুচিত (দ্রুত), x(t/2): প্রসারিত। Amplitude-এর গুণ (2x) শুধু উচ্চতা বদলায়। ক্রম মনে রাখো: x(−t+3) আঁকতে আগে x(−t), তারপর 3 দিয়ে shift (x(−(t−3)))।

Unit step u(t): t ≥ 0-তে 1, নইলে 0। u(−t) ঠিক উল্টো (t ≤ 0-তে 1)। এদের দিয়ে গুণ করলে signal-এর একটা অংশ "কেটে" নেওয়া যায়।

Impulse δ(t): একটি বিন্দুতে "অসীম" উচ্চতার ধারালো দাগ, মোট ক্ষেত্রফল 1। Sifting: x(t)*δ(t−t₀)=x(t−t₀) — মানে convolution-এ impulse signal-কে শুধু সরিয়ে দেয়। δ(at)=δ(t)/|a|।

System-এর তিন প্রশ্ন: Linear? দুটো input-এর যোগফলের output কি আলাদা output-এর যোগফল? Time-invariant? input দেরি করালে output কি শুধু দেরি হয়? Causal? output কি ভবিষ্যৎ input দেখে? (h(t)=0 for t<0 হলে causal)।

Correlation: দুটো signal কতটা মেলে তার মাপ: y(τ)=∫a(t)b(t−τ)dt। Zero lag-এ শুধু a(t)·b(t)-এর ক্ষেত্রফল।

Sampling = impulse train দিয়ে গুণ: spectrum-এর কপি হয় fs-এর গুণিতকে (ছোট ছোট ত্রিভুজ বারবার)।
