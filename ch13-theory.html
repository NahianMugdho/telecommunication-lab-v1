সহজ ভাষায় বুঝি — Discrete Signal

Sampling করলে কী হয়? x(t)-কে প্রতি 1/fs সেকেন্ডে মেপে x[n] = x(n/fs) পাই। cos(2πf·t) হয়ে যায় cos(2π(f/fs)·n)। এখানে f/fs হলো "প্রতি sample-এ কত চক্র"।

Periodic কবে? f/fs একটা ভগ্নাংশ p/q হলে (লঘিষ্ঠ আকারে) signal periodic এবং period N = q samples। নইলে aperiodic। উদাহরণ: x(t)=2cos(12000πt) মানে f=6000 Hz; fs=24000 হলে f/fs=1/4 ⇒ N=4 samples।

Digital frequency: ω₀ = 2πf/fs। cos(ω₀n)-এর period N = 2π/ω₀ (যদি পূর্ণসংখ্যা হয়)। দুটো tone যোগ হলে period = LCM(N₁, N₂)। মনে রাখো: একক "second" নয়, sample।

সহজ ভাষায় বুঝি — IP Subnetting

IP address = 32 bit, চার ভাগে। /n (prefix) মানে প্রথম n bit "network", বাকি (32−n) bit "host"। Subnet mask = প্রথম n bit সব 1, বাকি 0।

/23 হলে: host bit = 9 ⇒ মোট 2⁹ = 512 address, কিন্তু প্রথমটা (network) ও শেষটা (broadcast) ব্যবহার করা যায় না ⇒ valid host = 2⁹−2 = 510। Mask 255.255.254.0 (তৃতীয় octet-এ 7টি 1 + একটি 0 = 11111110 = 254)।

দ্রুত নিয়ম (block size): যে octet-এ prefix ভেঙেছে সেখানে block size = 256 − mask-এর মান। /23 ⇒ 256−254 = 2। তাই network 192.168.10.0 (10 জোড় ⇒ block শুরু), পরের network 192.168.12.0; এই block-এর broadcast = শেষ address = 192.168.11.255।

সূত্র: Network = IP AND Mask; Broadcast = network-এর host bit সব 1; First host = network+1; Last host = broadcast−1।
