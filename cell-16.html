🧠 সংক্ষেপ নোটShort note

Scripting মানে বারবার করতে হয় এমন কাজ কম্পিউটারকে দিয়ে করানো: simulation চালানো, ফলাফল আঁকা, আর শত শত router একসাথে কনফিগার করা।Scripting means letting the computer do repeated work: running simulations, plotting results, and configuring hundreds of routers at once.

  • Simulation: সূত্রে জটিল হলে কম্পিউটারে লক্ষ বার পরীক্ষা চালিয়ে ফল বের করা।Simulation: when the formula is too hard, run millions of trials on the computer and read the result.
  • Monte Carlo: এলোমেলো নমুনা নিয়ে গড় করা। নমুনা 100 গুণ বাড়ালে ভুল 10 গুণ কমে (ভুল ∝ 1/√N)।Monte Carlo: average over random samples. 100 times more samples cut the error 10 times (error ∝ 1/√N).
  • Configuration automation: CLI (Netmiko), NETCONF/YANG, RESTCONF, Ansible।Configuration automation: CLI (Netmiko), NETCONF/YANG, RESTCONF, Ansible.
  • NETCONF port 830 (SSH-এর ওপর)। YANG = ডেটা model ভাষা। SNMP port 161 = মনিটরিং।NETCONF port 830 (over SSH). YANG = the data-model language. SNMP port 161 = monitoring.

🧠 মনে রাখার কৌশল:Memory trick: "সংখ্যা বড় করো, ভুল ছোট করো": Monte Carlo-তে 100× নমুনা = 10× নির্ভুলতা।"Grow the number, shrink the error": in Monte Carlo 100× samples = 10× accuracy.

টপিক ৩-এর recursion হুবহু code-এ বসানো যায়:The recursion from Topic 3 translates straight into code:

def erlang_b(A, m): B = 1.0 for k in range(1, m + 1): B = A * B / (k + A * B) # B(A,m) = A*B(A,m-1) / (m + A*B(A,m-1)) return B for m in (16, 17, 18): print(m, round(erlang_b(10, m) * 100, 2), "%") # output: # 16 2.23 % # 17 1.29 % # 18 0.71 %

এই output-ই টপিক ৩-এর টেবিলের সংখ্যা: 2% সীমায় লাগে 17 channel।These numbers match the table in Topic 3: for a 2% limit you need 17 channels.

১৬.৩ Monte Carlo: BPSK-র BER16.3 Monte Carlo: BPSK BER

সূত্র BER = ½·erfc(√(Eb/N₀)) কম্পিউটারে সরাসরি পরীক্ষা করে দেখা যায়: এলোমেলো বিট পাঠাও, noise যোগ করো, ভুল গোনো।The formula BER = ½·erfc(√(Eb/N₀)) can be tested directly: send random bits, add noise and count the errors.

import numpy as np rng = np.random.default_rng(1) def ber_bpsk(ebn0_db, n_bits=1_000_000): ebn0 = 10 ** (ebn0_db / 10) bits = rng.integers(0, 2, n_bits) tx = 2 * bits - 1 # 0 -> -1, 1 -> +1 noise = rng.normal(0, np.sqrt(1 / (2 * ebn0)), n_bits) return np.mean(((tx + noise) > 0) != bits) print(ber_bpsk(6)) # about 0.0024 (theory: 0.5*erfc(sqrt(10**0.6)) = 0.00239)
Monte Carlo-র নির্ভুলতাMonte Carlo accuracy
relative error ≈ √( (1 − p) / (N · p) ) ∝ 1 / √N
p = আসল সম্ভাবনা, N = নমুনা। ভুল গোনার সংখ্যা N·p যত বেশি, ফল তত নির্ভরযোগ্য।p = true probability, N = samples. The more errors counted (N·p), the more reliable the result.
✍ p = 0.0024, N = 10⁶: √(0.9976 / 2400) ≈ 2% আপেক্ষিক ভুল। কম BER (যেমন 10⁻⁶) মাপতে অনেক বেশি নমুনা লাগে।p = 0.0024, N = 10⁶: √(0.9976 / 2400) ≈ 2% relative error. Measuring a tiny BER (e.g. 10⁻⁶) needs far more samples.
