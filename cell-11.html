Cellular Topic 11: Call Flow, Session Management ও Mobility Control

Theory • সহজ সারাংশ + বিস্তারিত নোট

এই অংশে প্রশ্ন আসে "কোন ধাপের পর কোন ধাপ" আর "কোন অবস্থা কী" নিয়ে। ক্রম মুখস্থ করা সবচেয়ে কাজের।

LTE Attach প্রক্রিয়া (সংক্ষেপে)

  1. UE চালু হয়ে cell খুঁজে RRC সংযোগ তৈরি করে, Attach Request পাঠায় (eNodeB হয়ে MME-তে)।

  2. MME HSS থেকে authentication তথ্য নেয়; UE ও নেটওয়ার্কের পারস্পরিক Authentication হয়।

  3. NAS Security Mode চালু, এনক্রিপশন ও integrity সুরক্ষা।

  4. MME Location Update করে HSS-এ, সাবস্ক্রিপশন প্রোফাইল পায়।

  5. MME S-GW ও P-GW-এর মাধ্যমে Default bearer তৈরি করে, P-GW UE-কে IP ঠিকানা দেয়।

  6. Attach Accept আসে, UE Attach Complete দেয়; এখন UE ডেটা পাঠাতে পারে।

অবস্থা (States)

স্তর অবস্থা অর্থ
EMM (LTE) DEREGISTERED / REGISTERED নেটওয়ার্কে নিবন্ধিত কি না
ECM (LTE) IDLE / CONNECTED সিগন্যালিং সংযোগ আছে কি না
RRC IDLE / CONNECTED (5G-তে + INACTIVE) রেডিও সংযোগ
5G RM RM-DEREGISTERED / RM-REGISTERED 5G নিবন্ধন
5G CM CM-IDLE / CM-CONNECTED NAS সংযোগ

Mobility ব্যবস্থাপনা

  • Idle mode: ফোন নিজে cell reselection করে। নেটওয়ার্ক জানে শুধু Tracking Area (TA) পর্যন্ত। TA বদলালে Tracking Area Update (TAU) পাঠায়। (GSM/3G-তে একই কাজ: Location Area Update / Routing Area Update।)

  • Paging: ইনকামিং কলে নেটওয়ার্ক TA-র সব cell-এ paging পাঠিয়ে UE-কে খোঁজে।

  • Connected mode handover: নেটওয়ার্ক-নিয়ন্ত্রিত, UE-র measurement রিপোর্ট (RSRP, RSRQ) দেখে।

    • X2 handover: eNodeB থেকে eNodeB সরাসরি (দ্রুত)।

    • S1 handover: MME-র মাধ্যমে, X2 না থাকলে।

    • ধাপ: Measurement → Handover Request → Resource বরাদ্দ → Handover Command → UE নতুন cell-এ যুক্ত → পুরনো রিসোর্স মুক্ত।

  • Service Request: idle UE ডেটা পাঠাতে চাইলে বা paging পেলে সংযোগ ফিরিয়ে আনে।

GSM mobile-terminated (ইনকামিং) কল

  1. কলার নম্বর ডায়াল → গেটওয়ে MSC (GMSC) HLR-কে জিজ্ঞেস করে গ্রহীতা কোথায় (SRI)।

  2. HLR গ্রহীতার বর্তমান VLR/MSC থেকে MSRN (অস্থায়ী roaming নম্বর) নিয়ে ফেরত দেয়।

  3. GMSC কলটি সেই MSC-তে রুট করে; MSC paging করে, গ্রহীতা সাড়া দিলে কল সংযুক্ত হয়।

5G Registration ও PDU Session

  • Registration: UE → gNB → AMF; AMF AUSF/UDM দিয়ে authenticate করে, সাবস্ক্রিপশন নেয়, 5G-GUTI দেয়।

  • PDU Session Establishment: UE → AMF → SMF; SMF UPF বেছে নেয় ও PCF থেকে নীতি পায়; IP ঠিকানা ও QoS Flow তৈরি হয়। 4G-র bearer-এর বদলে 5G-তে PDU Session ও QoS Flow।

সম্ভাব্য MCQ

  • ফোন idle থাকলে নেটওয়ার্ক তার অবস্থান কোন পর্যন্ত জানে? → Tracking Area পর্যন্ত

  • LTE Attach-এ authentication তথ্য আসে কোথা থেকে? → HSS

  • eNodeB-গুলোর মধ্যে সরাসরি handover কোন ইন্টারফেসে? → X2

  • MSRN কী এবং কোথা থেকে আসে? → ইনকামিং কল রুট করার অস্থায়ী roaming নম্বর; গ্রহীতার বর্তমান VLR/MSC দেয়, HLR সেটি GMSC-কে জানায়

  • 5G-তে session ব্যবস্থাপনা করে কোন NF? → SMF

বিস্তারিত নোট

১১.১ তিন ধরনের ব্যবস্থাপনা

  • Mobility Management (MM): ইউজার কোথায় আছে তা জানা, নিবন্ধন, authentication, handover।

  • Session Management (SM): ডেটা সেশন (bearer/PDU session) তৈরি, পরিবর্তন, বন্ধ; IP ও QoS।

  • Call/Connection Control: কল বা সংযোগের সেটআপ ও release (CS-এ CC, IMS-এ SIP)।

NAS (Non-Access Stratum) বার্তা UE ও core-এর (MME/AMF) মধ্যে সরাসরি যায়, eNB/gNB শুধু বহন করে। AS (Access Stratum) বার্তা UE ও eNB/gNB-র মধ্যে (RRC)।

১১.২ অবস্থা মডেল

স্তর অবস্থা অর্থ
EMM (NAS, 4G) EMM-DEREGISTERED, EMM-REGISTERED নেটওয়ার্কে নিবন্ধিত কি না
ECM (NAS, 4G) ECM-IDLE, ECM-CONNECTED UE ও MME-র মধ্যে signalling সংযোগ আছে কি না
RRC (AS, 4G) RRC_IDLE, RRC_CONNECTED রেডিও সংযোগ
RRC (AS, 5G) RRC_IDLE, RRC_INACTIVE, RRC_CONNECTED INACTIVE: core সংযোগ রেখে রেডিও আংশিক বন্ধ, দ্রুত পুনঃসংযোগ
RM (5G NAS) RM-DEREGISTERED, RM-REGISTERED 5G নিবন্ধন
CM (5G NAS) CM-IDLE, CM-CONNECTED NAS signalling সংযোগ

Idle mode: ফোন নিজে cell বেছে নেয় (cell selection/reselection), নেটওয়ার্ক জানে Tracking Area (TA) পর্যন্ত। ব্যাটারি বাঁচাতে DRX (Discontinuous Reception): ফোন নির্দিষ্ট বিরতিতে (যেমন 1.28 s) জেগে paging দেখে।

১১.৩ Random Access ও RRC সংযোগ (LTE)

ফোন connected হতে চাইলে চার ধাপের contention-based random access:

  1. Msg1: random access preamble (64টির একটি) RACH-এ।

  2. Msg2: Random Access Response: timing advance, uplink grant, temporary C-RNTI।

  3. Msg3: RRC Connection Request (UE-র পরিচয়)।

  4. Msg4: contention resolution ও RRC Connection Setup।

তারপর UE RRC Connection Setup Complete পাঠায়, যার ভেতরে NAS বার্তা (যেমন Attach Request) থাকে।

১১.৪ LTE Attach (বিস্তারিত ক্রম)

  1. RACH ও RRC Connection Setup (ওপরের ধাপ); NAS Attach Request + PDN Connectivity Request UE থেকে।

  2. eNB → MME: Initial UE Message (S1AP) (Attach Request সহ)।

  3. MME → HSS: Authentication Information Request; HSS authentication vector (RAND, AUTN, XRES, KASME) ফেরত দেয়।

  4. MME → UE: Authentication Request (RAND, AUTN); UE AUTN যাচাই করে RES ফেরত পাঠায়; MME RES = XRES মেলায়।

  5. NAS Security Mode Command/Complete: encryption ও integrity অ্যালগরিদম বেছে নেওয়া।

  6. MME → HSS: Update Location Request; HSS সাবস্ক্রিপশন (APN, QoS, AMBR) ফেরত দেয়।

  7. MME → S-GW: Create Session Request (S11) → S-GW → P-GW (S5); P-GW IP ঠিকানা বরাদ্দ করে ও (PCRF-এর সাথে policy মিলিয়ে) Create Session Response দেয়।

  8. MME → eNB: Initial Context Setup Request (Attach Accept সহ: GUTI, TAI list, IP ঠিকানা, default bearer QoS)।

  9. eNB → UE: RRC Connection Reconfiguration (radio bearer সেটআপ + Attach Accept); UE সম্পন্ন জানায়।

  10. UE Attach Complete পাঠায়; MME → S-GW Modify Bearer Request (eNB-র TEID) ⇒ ডাউনলিংক পথ চালু।

ফল: UE এখন EMM-REGISTERED ও ECM-CONNECTED, একটি default bearer ও IP ঠিকানাসহ। কিছুক্ষণ নিষ্ক্রিয় থাকলে UE-র ECM-IDLE ও RRC_IDLE-এ নামে (S1 release)।

১১.৫ Service Request, Paging ও Detach

  • Service Request: idle ইউজার ডেটা পাঠাতে চাইলে (বা paging-এর উত্তরে) connected হয়; bearer-এর রেডিও অংশ পুনঃস্থাপিত হয়। UE-কে IP ঠিকানা আবার নিতে হয় না।

  • Paging: নেটওয়ার্কে ইউজারের জন্য ডেটা/কল এলে MME TA list-এর সব eNB-তে paging পাঠায় (S1AP), eNB রেডিওতে প্রচার করে; UE সাড়া দেয়।

  • Detach: UE-initiated (বন্ধ করলে) বা network-initiated; bearer ও context মুছে যায়।

  • Tracking Area Update (TAU): TA list-এর বাইরে গেলে বা periodic timer শেষে; MME অবস্থান হালনাগাদ করে (GSM-এ Location Update, GPRS-এ Routing Area Update)।

১১.৬ LTE Handover (বিস্তারিত)

Measurement ও trigger: UE প্রতিবেশী cell মেপে রিপোর্ট দেয়। সংকেত মাপার একক: RSRP (Reference Signal Received Power, পরিসর প্রায় −140 থেকে −44 dBm), RSRQ (প্রায় −19.5 থেকে −3 dB), SINR। ঘটনা: A1 (serving ভালো), A2 (serving খারাপ), A3 (প্রতিবেশী serving-এর চেয়ে offset-এ ভালো; সবচেয়ে সাধারণ handover trigger), A4, A5। ping-pong এড়াতে hysteresis ও time-to-trigger (TTT) ব্যবহৃত হয়।

X2 handover (সরাসরি eNB–eNB):

  1. Source eNB measurement রিপোর্ট দেখে সিদ্ধান্ত নেয় → X2-তে Handover Request target eNB-কে।

  2. Target resource বরাদ্দ করে Handover Request Acknowledge (target-এর নতুন config সহ)।

  3. Source UE-কে RRC Connection Reconfiguration (mobility control info) পাঠায় (handover command); ডেটা source থেকে target-এ ফরওয়ার্ড শুরু।

  4. UE target cell-এ synchronize ও RACH করে; RRC Reconfiguration Complete পাঠায়।

  5. Target → MME Path Switch Request; MME → S-GW Modify Bearer; পথ target-এ সরে; Path Switch Acknowledge।

  6. Target → source UE Context Release; পুরনো রিসোর্স মুক্ত।

S1 handover: eNB-দের মধ্যে X2 না থাকলে বা MME/S-GW বদলাতে হলে MME-র মাধ্যমে (Handover Required → Handover Request → …)। Inter-RAT (4G→3G/2G): SGSN/MSC-র সাথে সমন্বয়, SRVCC voice-এর জন্য।

লক্ষ্য: handover-এ ডেটা বন্ধ থাকার সময় (interruption) কয়েক দশ ms; LTE-তে make-before-break নয়, hard handover।

১১.৭ GSM Location Update ও রুটিং

  • IMSI Attach: ফোন চালু হলে নেটওয়ার্কে জানায়; Location Update অন্য Location Area-তে গেলে (সাথে VLR আপডেট; নতুন VLR HLR-কে জানায়, পুরনো VLR-এর রেকর্ড মোছা হয় (Cancel Location))। Periodic Location Update: নির্দিষ্ট সময় পরপর, যাতে নেটওয়ার্ক জানে ফোন আছে।

  • TMSI re-allocation: পরিচয় গোপন রাখতে অস্থায়ী নম্বর বদলানো।

  • Roaming কল (MT): GMSC → HLR (SRI) → HLR ভিজিটেড VLR-কে PRN (Provide Roaming Number) → MSRN → GMSC কল রাউট করে।

১১.৮ 5G Registration ও PDU Session

Registration (initial):

  1. UE → gNB: RRC setup; Registration Request (SUCI, requested NSSAI) NAS-এ; gNB → AMF (N2)।

  2. AMF → AUSF → UDM: authentication (5G-AKA বা EAP-AKA')।

  3. NAS security mode।

  4. AMF → UDM: সাবস্ক্রিপশন ডেটা (Nudm_SDM) ও registration নিবন্ধন (Nudm_UECM)।

  5. AMF → PCF (যদি প্রয়োজন): access/mobility policy।

  6. AMF → UE: Registration Accept (5G-GUTI, Allowed NSSAI, TAI list)।

  7. UE Registration Complete।

PDU Session Establishment:

  1. UE → AMF: PDU Session Establishment Request (S-NSSAI, DNN, session ID)।

  2. AMF → SMF নির্বাচন (NRF/NSSF); Nsmf_PDUSession_CreateSMContext।

  3. SMF → UDM: সাবস্ক্রিপশন; SMF → PCF: session policy।

  4. SMF → UPF: N4 Session Establishment (PFCP): packet detection ও forwarding নিয়ম।

  5. SMF → AMF: N2 SM info (QoS Flow, UPF tunnel তথ্য) ও N1 SM (Accept); AMF → gNB: PDU Session Resource Setup Request।

  6. gNB ও UE: রেডিও bearer (DRB) সেটআপ; UE-কে IP ঠিকানা।

  7. ডেটা UE ↔︎ gNB ↔︎ UPF (N3, GTP-U) ↔︎ ইন্টারনেট (N6)।

5G handover: Xn handover (gNB–gNB সরাসরি) বা N2 handover (AMF-এর মাধ্যমে); 4G↔︎5G N26 দিয়ে।

১১.৯ অনুশীলন

  1. LTE Attach-এ ইউজারের IP ঠিকানা কখন বরাদ্দ হয়? → P-GW-র Create Session Response-এ (Attach Accept-এ UE পায়)।

  2. সবচেয়ে সাধারণ handover trigger event? → A3।

  3. Random access-এর Msg3 কী? → RRC Connection Request।

  4. 5G-তে নতুন RRC অবস্থা? → RRC_INACTIVE।

  5. X2 handover-এ path switch কে শুরু করে? → Target eNB (MME-কে Path Switch Request)।
