Topic 11: Call Flow, Session Management ও Mobility ControlCall Flow, Session Management and Mobility Control

Theory • সহজ সারাংশ + বিস্তারিত নোটTheory • short note + detailed note

🧠 সংক্ষেপ নোটShort note

Call flow মানে একটি কাজ (ফোন চালু, কল, handover) শুরু থেকে শেষ পর্যন্ত নোডগুলোর মধ্যে কোন বার্তা কোন ক্রমে যায় তার তালিকা। এটা মুখস্থ করার চেয়ে গল্প হিসেবে বোঝা সহজ।A call flow is the list of which messages go between nodes, and in what order, for one task (power-on, call, handover). It is easier to understand as a story than to memorize.

  • LTE Attach: PRACH → RRC Setup → Attach Request → Authentication → Security → Create Session → Attach Accept।LTE Attach: PRACH → RRC setup → Attach Request → Authentication → Security → Create Session → Attach Accept.
  • Idle: ফোন ঘুমন্ত, শুধু TAU করে (নতুন Tracking Area বা timer)। Connected: কল চলছে, mobility = handover।Idle: phone asleep, only does TAU (new Tracking Area or timer). Connected: call on, mobility = handover.
  • Service Request: idle ফোন ডেটা পাঠাতে সংযোগ ফেরায়। ডেটা আসলে আগে Paging।Service Request: an idle phone restores its connection to send data. For incoming data, Paging comes first.
  • X2 handover: Source → Target সরাসরি। শেষে Target Path Switch Request MME-কে পাঠায়।X2 handover: Source → Target directly. At the end the Target sends a Path Switch Request to the MME.
  • GSM: ফোন channel বরাদ্দ চায় RACH-এ, বরাদ্দ আসে AGCH-এ।GSM: the phone asks for a channel on RACH and the grant comes on AGCH.

🧠 মনে রাখার কৌশল:Memory trick: Attach-এর গল্প: "হ্যালো বলি (PRACH) → সংযোগ নিই (RRC) → পরিচয় দিই (Attach) → প্রমাণ দিই (Auth) → লুকিয়ে কথা (Security) → ঠিকানা পাই (Session) → ঢুকে পড়ি (Accept)।"The attach story: "say hello (PRACH) → get a link (RRC) → give identity (Attach) → prove it (Auth) → talk secretly (Security) → get an address (Session) → I am in (Accept)."

১১.২ Idle, Paging, Service Request, TAU11.2 Idle, paging, service request, TAU
  • ECM-IDLE: ফোন নেটওয়ার্কের সাথে RRC সংযোগ ছেড়ে ঘুমায়। ব্যাটারি বাঁচে।ECM-IDLE: the phone drops its RRC link and sleeps. Saves battery.
  • Paging: ডেটা আসলে MME Tracking Area-র সব cell-এ ফোনকে ডাকে।Paging: when data arrives the MME calls the phone in all cells of the Tracking Area.
  • Service Request: ফোন ডাকের উত্তরে (বা নিজে ডেটা পাঠাতে) সংযোগ ফিরিয়ে আনে।Service Request: the phone restores the connection in answer to paging (or to send its own data).
  • TAU (Tracking Area Update): ফোন নতুন Tracking Area-তে গেলে বা periodic timer-এ নেটওয়ার্ককে জানায়। কল চলাকালীন TAU নয়, handover।TAU (Tracking Area Update): the phone tells the network when it enters a new Tracking Area or when a periodic timer expires. During a call it is a handover, not a TAU.

১১.৪ GSM-এ কল সেটআপ (ধাপ)11.4 GSM call setup (steps)
  1. ফোন RACH-এ channel চায় (Channel Request)।The phone asks for a channel on the RACH (Channel Request).
  2. নেটওয়ার্ক AGCH-এ SDCCH বরাদ্দ জানায় (Immediate Assignment)।The network announces an SDCCH on the AGCH (Immediate Assignment).
  3. CM Service Request, তারপর Authentication ও Ciphering।CM Service Request, then authentication and ciphering.
  4. Setup বার্তায় গন্তব্য নম্বর যায়; MSC কল রুট করে।The destination number goes in the Setup message; the MSC routes the call.
  5. Assignment: ফোন SDCCH ছেড়ে TCH (ভয়েস channel)-এ যায়।Assignment: the phone moves from the SDCCH to a TCH (voice channel).
  6. Alerting (রিং) → Connect (ফোন ধরা) → কথা।Alerting (ring) → Connect (answer) → talk.
