🧠 সংক্ষেপ নোটShort note

একটা বড় শহরকে অনেক ছোট ছোট ঘরে (cell) ভাগ করো, প্রতিটিতে একটি টাওয়ার। দূরের ঘরে একই ফ্রিকোয়েন্সি আবার ব্যবহার করো। এতে অল্প ফ্রিকোয়েন্সিতেই অনেক মানুষ একসাথে কথা বলতে পারে।Cut a big city into many small "rooms" (cells), each with one tower. Reuse the same frequency in far-away rooms. This lets many people talk at once using little spectrum.

  • Cell = একটি টাওয়ারের এলাকা। হিসাবের সুবিধার জন্য ষড়ভুজ (hexagon) আঁকা হয়।Cell = the area of one tower. Drawn as a hexagon to make calculation easy.
  • Cluster (N) = কয়েকটি পাশাপাশি cell, যারা মিলে সব ফ্রিকোয়েন্সি ভাগ করে নেয়। যেমন N = 7।Cluster (N) = a group of neighbouring cells that share all the frequencies between them. For example N = 7.
  • Frequency reuse = একই ফ্রিকোয়েন্সি দূরের অন্য cluster-এ আবার ব্যবহার।Frequency reuse = using the same frequency again in a far cluster.
  • SIR = নিজের সিগন্যাল ÷ একই ফ্রিকোয়েন্সির দূরের cell-গুলোর বিরক্তি। যত বেশি, তত ভালো।SIR = own signal ÷ interference from far cells using the same frequency. Higher is better.
  • Handoff = কথা চলার সময় টাওয়ার বদল। Roaming = অন্য নেটওয়ার্কে সেবা পাওয়া।Handoff = changing tower during a call. Roaming = getting service on another network.
  • Capacity বাড়ানোর উপায়: cell splitting, sectoring, ছোট cell (micro/pico)।Ways to add capacity: cell splitting, sectoring, smaller cells (micro/pico).
  • Erlang-B: কতগুলো channel থাকলে কত শতাংশ কল আটকে যাবে তার হিসাব।Erlang-B: tells what percent of calls get blocked for a given number of channels.
  • GSM: 200 kHz carrier, ৮টি time slot, মোট গতি 270.833 kbps।GSM: 200 kHz carrier, 8 time slots, total rate 270.833 kbps.

🧠 মনে রাখার কৌশল:Memory trick: Cell = ঘর, Cluster = পাড়া, N = পাড়ায় ঘরের সংখ্যা। N বাড়ালে বিরক্তি কমে (SIR বাড়ে), কিন্তু প্রতি ঘরের channel কমে। দুটোর মধ্যে ভারসাম্য রাখতে হয়।Cell = room, cluster = neighbourhood, N = rooms per neighbourhood. A bigger N means less disturbance (higher SIR) but fewer channels per room. It is always a trade-off.

📖 বিস্তারিত নোটDetailed note

৩.১ কেন cellular?3.1 Why cellular?

আগে একটি বিশাল টাওয়ার পুরো শহর ঢাকত। সমস্যা: ওই টাওয়ারের হাতে মাত্র কয়েকটি channel, তাই অল্প কিছু মানুষই একসাথে কথা বলতে পারত। আবার দূরের ফোনকে ধরতে অনেক বেশি power লাগত।Earlier one huge tower covered a whole city. Problem: it had only a few channels, so only a few people could talk at once. Far phones also needed a lot of power.

🛵 উপমা:Analogy: একটি বাজারে একজন মাইক দিয়ে চিৎকার করছে: একসময়ে একজনই বলতে পারে। এবার বাজারটাকে ছোট ছোট দোকানে ভাগ করো, প্রতিটিতে ছোট স্পিকার। এখন সবাই একসাথে কথা বলতে পারে। আবার দূরের দুই দোকানে একই "চ্যানেল" ব্যবহার করলেও কেউ কারো শব্দ শোনে না।In a market one man shouts through a mic: only one person can speak at a time. Now split the market into small shops, each with a small speaker. Everyone can talk together. Two far shops can even use the same "channel" without hearing each other.

৩.২ Hexagon জ্যামিতি ও Cluster3.2 Hexagon geometry and clusters

Cell আসলে গোল, কিন্তু গোল আকার দিয়ে মানচিত্র ঢাকলে ফাঁক থেকে যায়। ফাঁক ছাড়া ঢাকা যায় এমন আকারের মধ্যে hexagon সবচেয়ে গোলের কাছাকাছি, তাই টাওয়ার কম লাগে। তাই সবাই hexagon ধরে হিসাব করে।A cell is really round, but circles leave gaps when covering a map. Among shapes that tile without gaps, the hexagon is closest to a circle, so fewer towers are needed. That is why everyone calculates with hexagons.

Hexagon-এর ক্ষেত্রফলArea of a hexagon cell
A = (3√3 / 2) · R² ≈ 2.598 · R²
R = কেন্দ্র থেকে কোণের দূরত্ব (cell radius)।R = distance from centre to a corner (cell radius).
✍ R = 2 km হলে A = 2.598 × 2² = 10.39 km²।If R = 2 km then A = 2.598 × 2² = 10.39 km².
Cluster sizeCluster size

N যত বড়, D তত বেশি, তাই বিরক্তি তত কম।The bigger N, the larger D, so less interference.

৩.৩ Co-channel Interference ও SIR3.3 Co-channel interference and SIR

একই ফ্রিকোয়েন্সি ব্যবহার করা দূরের cell-এর সিগন্যাল তোমার কলে বিরক্তি (interference) তৈরি করে। এর মধ্যে সবচেয়ে কাছের ৬টি cell (first tier) সবচেয়ে বেশি ক্ষতি করে।Far cells that use the same frequency add interference to your call. The nearest 6 (first tier) hurt the most.

দূরত্ব বাড়লে সিগন্যাল দুর্বল হয়, দূরত্বের γ ঘাতে (path loss exponent)। γ = 2 ফাঁকা জায়গায়, শহরে সাধারণত 3 থেকে 4।Signals weaken with distance, as distance to the power γ (path loss exponent). γ = 2 in free space, usually 3 to 4 in a city.

SIR বের করার ধাপDeriving SIR step by step
S ∝ R−γ, প্রতিটি interferer ∝ D−γ, মোট I = 6 · D−γ
SIR = S / I = (D/R)γ / 6 = (3N)γ/2 / 6
S = নিজের টাওয়ারের সিগন্যাল, I = ৬টি interferer-এর যোগফল।S = signal from own tower, I = sum of the 6 interferers.
✍ N = 7, γ = 4: (21)² ÷ 6 = 441 ÷ 6 = 73.5। dB-তে 10·log10(73.5) = 18.7 dB।N = 7, γ = 4: 21² ÷ 6 = 441 ÷ 6 = 73.5. In dB: 10·log10(73.5) = 18.7 dB.

💡 পুরোনো analog (AMPS)-এ প্রায় 18 dB লাগত, তাই N = 7 বেছে নেওয়া হয়েছিল। GSM-এ coding ও frequency hopping থাকায় প্রায় 9–12 dB হলেই চলে, তাই ছোট N (যেমন 3 বা 4) ব্যবহার করা যায় এবং ক্ষমতা বাড়ে।Old analog (AMPS) needed about 18 dB, so N = 7 was chosen. GSM has coding and frequency hopping, so about 9–12 dB is enough. A smaller N (3 or 4) can be used, which gives more capacity.

৩.৪ Capacity বাড়ানোর কৌশল3.4 Ways to increase capacity
Cell splitting (cell ছোট করা)Cell splitting (making cells smaller)
নতুন cell সংখ্যা = (Rold / Rnew)², Pt,new = Pt,old · (Rnew / Rold)γ
ক্ষেত্রফল R²-এর সমানুপাতিক, তাই ব্যাসার্ধ আধা করলে cell সংখ্যা 4 গুণ। পাশাপাশি transmit power কমাতে হয়, নইলে বিরক্তি বাড়ে।Area is proportional to R², so halving the radius gives 4 times the cells. Transmit power must also drop or interference rises.
✍ R আধা, γ = 4: cell = 4 গুণ, power = (1/2)⁴ = 1/16 (12 dB কম)।R halved, γ = 4: cells ×4, power = (1/2)⁴ = 1/16 (12 dB lower).
Sectoring (দিক ভাগ করা)Sectoring (splitting by direction)
SIR = (D/R)γ / i0, i0 = 6 (omni), 2 (120° sector), 1 (60° sector)
অ্যান্টেনা এক দিকে জোরালো হলে অন্য দিকের interferer কম শোনে।A directional antenna hears fewer interferers from other directions.
✍ N = 7, γ = 4: 120° এ 441/2 = 220.5 → 23.4 dB; 60° এ 441 → 26.4 dB।N = 7, γ = 4: 120° gives 441/2 = 220.5 → 23.4 dB; 60° gives 441 → 26.4 dB.

৩.৫ Trunking ও Erlang-B3.5 Trunking and Erlang-B

সবাই একই মুহূর্তে কল করে না। তাই প্রতিজনের জন্য আলাদা channel রাখার বদলে কম সংখ্যক channel সবাই ভাগ করে নেয়। একেই trunking বলে।Not everyone calls at the same moment. So instead of one channel per person, a smaller pool of channels is shared. This is called trunking.

🛵 উপমা:Analogy: বাসস্টপে সবার জন্য আলাদা বাস রাখতে হয় না। কয়েকটি বাসই সবাইকে বহন করে। শুধু ভিড়ের সময় কেউ কেউ বাস পায় না।A bus stop does not need one bus per person. A few buses carry everyone. Only at rush hour, some people miss a bus.

Traffic (Erlang)Traffic (Erlang)
A = λ · h
λ = প্রতি ঘণ্টায় কল সংখ্যা, h = গড় কলের সময় (ঘণ্টায়)। 1 Erlang = একটি channel পুরো সময় ব্যস্ত।λ = calls per hour, h = average call length (in hours). 1 Erlang = one channel busy all the time.
✍ প্রতি ঘণ্টায় 120 কল, গড় 3 মিনিট: A = 120 × (3/60) = 6 Erlang। অথবা 1000 জন × 25 mE = 25 Erlang।120 calls per hour, 3 min each: A = 120 × (3/60) = 6 Erlang. Or 1000 users × 25 mE = 25 Erlang.
Erlang-B (আটকে যাওয়া কলের সম্ভাবনা)Erlang-B (probability a call is blocked)
B(A, 0) = 1, B(A, m) = A · B(A, m−1) / ( m + A · B(A, m−1) )
A = traffic, m = channel সংখ্যা। এই পদ্ধতিতে একটার পর একটা m বাড়িয়ে হিসাব করা যায়।A = traffic, m = number of channels. Compute by raising m one at a time.
✍ A = 1, m = 1: B = 1·1/(1+1·1) = 0.5 (50%)।A = 1, m = 1: B = 1·1/(1+1·1) = 0.5 (50%).

৩.৬ Handoff, Roaming ও Paging3.6 Handoff, roaming and paging
  • Hard handoff: আগের সংযোগ কেটে নতুন টাওয়ারে সংযোগ (GSM)। কয়েক মিলিসেকেন্ডের ফাঁক।Hard handoff: break the old link, then make the new one (GSM). A gap of a few milliseconds.
  • Soft handoff: আগে নতুন টাওয়ারে যুক্ত, তারপর পুরোনোটা ছাড়া (CDMA/WCDMA)।Soft handoff: join the new tower first, then drop the old one (CDMA/WCDMA).
  • Hysteresis margin: নতুন টাওয়ার নির্দিষ্ট dB বেশি শক্তিশালী না হলে বদলায় না। এতে ফোন বারবার দুই টাওয়ারের মধ্যে লাফায় না (ping-pong)।Hysteresis margin: switch only if the new tower is stronger by a set number of dB. This stops the phone bouncing between two towers (ping-pong).
  • MAHO: GSM-এ ফোন নিজেই আশপাশের টাওয়ার মেপে নেটওয়ার্ককে রিপোর্ট করে।MAHO: in GSM the phone itself measures nearby towers and reports to the network.

৩.৭ GSM-এর সংখ্যাগুলো কোথা থেকে এল (সূত্রসহ)3.7 Where the GSM numbers come from (with formulas)

GSM-এর প্রতিটি সংখ্যা আসলে একটি সরল হিসাবের ফল। ধাপে ধাপে দেখো:Every GSM number is the result of a simple calculation. Follow it step by step:

ধাপ ১: ARFCN সংখ্যা (carrier)Step 1: number of ARFCN (carriers)
NARFCN = 25 MHz / 200 kHz = 125 → 1টি guard বাদ → 124
FUL(n) = 890 + 0.2·n MHz, FDL(n) = FUL(n) + 45 MHz
n = 1 থেকে 124। যেমন n = 1: UL = 890.2 MHz, DL = 935.2 MHz।n = 1 to 124. For n = 1: UL = 890.2 MHz, DL = 935.2 MHz.
ধাপ ২: Bit সময় (GSM-এর 13 MHz ঘড়ি থেকে)Step 2: bit time (from the GSM 13 MHz clock)
Tb = 48 / 13 MHz = 3.6923 µs ⇒ bit rate = 13 MHz / 48 = 270.833 kbps
GMSK-এ প্রতি symbol-এ 1 bit, তাই symbol rate = 270.833 ksymbol/s।GMSK carries 1 bit per symbol, so the symbol rate = 270.833 ksymbol/s.
ধাপ ৩: Slot ও frameStep 3: slot and frame
Tslot = 156.25 × 3.6923 µs = 576.9 µs (≈ 0.577 ms)
Tframe = 8 × 576.9 µs = 4.615 ms
প্রতি slot-এ 156.25 bit-সময়: 148 bit-এর burst + 8.25 bit guard।Each slot has 156.25 bit-times: a 148-bit burst plus 8.25 bits of guard.
✍ যাচাই: 156.25 × 8 ÷ 4.615 ms = 1250 bit ÷ 4.615 ms = 270.8 kbps ✓Check: 156.25 × 8 ÷ 4.615 ms = 1250 bits ÷ 4.615 ms = 270.8 kbps ✓
ধাপ ৪: Normal burst-এর গঠনStep 4: structure of a normal burst
3 (tail) + 57 (data) + 1 (flag) + 26 (training) + 1 (flag) + 57 (data) + 3 (tail) = 148 bit
Training sequence-এর কাজ channel পরিমাপ ও equalization। কাজের ডেটা 57 + 57 = 114 bit।The training sequence helps measure the channel and equalize. Useful data = 57 + 57 = 114 bits.
ধাপ ৫: এক user-এর গতিStep 5: data rate of one user
26-frame multiframe = 26 × 4.615 ms = 120 ms: 24 traffic + 1 SACCH + 1 idle
গতি = 24 × 114 bit / 120 ms = 2736 / 0.12 s = 22.8 kbps
এর মধ্যেই ভয়েসের 13 kbps এবং error-correction coding মিলিয়ে আছে।This already includes 13 kbps of voice plus error-correction coding.
✍ Speech: 260 bit / 20 ms = 13 kbps (RPE-LTP)। coding-এর পর 456 bit / 20 ms = 22.8 kbps ✓Speech: 260 bits / 20 ms = 13 kbps (RPE-LTP). After coding: 456 bits / 20 ms = 22.8 kbps ✓
ধাপ ৬: Hop rate ও সর্বোচ্চ cell sizeStep 6: hop rate and maximum cell size
hop rate = 1 / 4.615 ms = 217 hop/s (প্রতি frame-এ একবার)
1 TA step = Tb × c / 2 = 3.69 µs × 3×108 / 2 ≈ 554 m; 63 × 554 m ≈ 35 km
TA = Timing Advance (ফোন কতটা আগে পাঠাবে)। সর্বোচ্চ মান 63।TA = Timing Advance (how early the phone must transmit). Maximum value is 63.
ধাপ ৭: Multiframe, superframe, hyperframeStep 7: multiframe, superframe, hyperframe
traffic multiframe = 26 frame = 120 ms, control multiframe = 51 frame = 235.4 ms
superframe = 51 × 26 = 1326 frame = 6.12 s, hyperframe = 2048 superframe ≈ 3 h 28 min
Hyperframe-এ কাউন্টার ঘুরে আসে। encryption key-র সাথে frame নম্বর মিলিয়ে ব্যবহার হয়।The frame counter wraps at the hyperframe. The frame number is mixed into the encryption.

Hysteresis margin: নতুন টাওয়ার নির্দিষ্ট dB বেশি ভালো না হলে handoff হয় না।Hysteresis margin: no handoff unless the new tower is better by a set number of dB.
