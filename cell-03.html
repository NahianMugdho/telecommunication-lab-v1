Cellular নেটওয়ার্কের মূল আইডিয়া: একটি বড় এলাকাকে অনেক ছোট ছোট cell-এ ভাগ করা, প্রতিটিতে একটি base station। একই ফ্রিকোয়েন্সি দূরের অন্য cell-এ আবার ব্যবহার করা হয়, একেই frequency reuse বলে। এতে সীমিত spectrum দিয়ে অসংখ্য ইউজার সামলানো যায়।

মূল শব্দ

  • Cell: একটি base station-এর কভারেজ এলাকা (আদর্শ আকার hexagon)।

  • Cluster: যে cell-গুলো মিলে সব ফ্রিকোয়েন্সি একবার ব্যবহার করে; আকার N।

  • Co-channel interference: একই ফ্রিকোয়েন্সির দূরের cell-এর বাধা।

  • Handoff/Handover: কল চলাকালীন এক cell থেকে আরেক cell-এ সংযোগ সরানো।

  • Roaming: নিজের নেটওয়ার্কের বাইরে অন্য এলাকা/অপারেটরে সেবা পাওয়া।

গুরুত্বপূর্ণ সূত্র

N=i2+ij+j2D=R3N​Reuse factor=N1​

  • N-এর সম্ভাব্য মান: 1, 3, 4, 7, 9, 12 (7 সবচেয়ে বেশি আলোচিত)।

  • D = co-channel cell-এর মধ্যে দূরত্ব, R = cell radius। N বাড়লে D/R বাড়ে, interference কমে কিন্তু প্রতি cell-এ channel কমে।

  • মোট channel S হলে প্রতি cell-এ k = S/N channel।

  • Hexagon cell-এর ক্ষেত্রফল = (3√3 / 2) R²।

কৌশল কাজ

Handoff-এর ধরন

  • Hard handoff: আগের সংযোগ কেটে নতুন সংযোগ (break-before-make); GSM, LTE।

  • Soft handoff: একসাথে একাধিক cell-এর সাথে যুক্ত (make-before-break); CDMA/WCDMA।

  • Intra-/Inter-system: একই প্রযুক্তির ভেতরে বা ভিন্ন প্রযুক্তির মধ্যে (যেমন 4G→3G)।

  • Handover ঠিক করে সংকেত মান (RSRP/RSRQ) ও থ্রেশহোল্ড; অকারণ ping-pong এড়াতে hysteresis রাখা হয়।

GSM আর্কিটেকচার (পরীক্ষায় খুব আসে)

  • MS (মোবাইল + SIM) → BTS (রেডিও ট্রান্সসিভার) → BSC (BTS নিয়ন্ত্রণ, handover, channel বরাদ্দ) → MSC (কল সুইচিং)।

  • HLR: সাবস্ক্রাইবারের স্থায়ী ডেটাবেস। VLR: বর্তমান এলাকার অস্থায়ী ডেটা। AuC: authentication key। EIR: চুরি/অবৈধ ডিভাইসের IMEI তালিকা।

  • BTS+BSC মিলে BSS; MSC, VLR, HLR, AuC, EIR মিলে NSS।

বিস্তারিত নোট

৩.১ কেন cellular?

পুরনো মোবাইল ব্যবস্থায় একটি উঁচু টাওয়ার ও বেশি শক্তির transmitter পুরো শহর কভার করত, ফলে মোট channel ছিল হাতে গোনা (কয়েক ডজন ইউজার)। Cellular ধারণায় এলাকাকে ছোট cell-এ ভাগ করা হয়, প্রতিটিতে কম শক্তির base station থাকে, আর একই ফ্রিকোয়েন্সি দূরের cell-এ আবার ব্যবহৃত হয় (frequency reuse)। ফলে একই spectrum দিয়ে লাখো ইউজার সামলানো যায়। মূল সুবিধা তিনটি: বেশি capacity, কম transmit power (ফোনের ব্যাটারি বাঁচে), এবং সহজে কভারেজ বাড়ানো।

৩.২ Hexagon জ্যামিতি ও cluster

বাস্তবে cell গোলাকার, কিন্তু ফাঁক বা overlap ছাড়া পুরো এলাকা ঢাকতে হেক্সাগন সবচেয়ে কাছের আদর্শ আকার। R ব্যাসার্ধের হেক্সাগনের ক্ষেত্রফল = (3√3/2)R² ≈ 2.598R²।

N=i2+ij+j2D=R3N​q=RD​=3N​

(1,0) 1 1.73 LTE/5G-তে reuse-1
(1,1) 3 3.00 সাধারণ sector-ভিত্তিক
(2,0) 4 3.46 AMPS-এর ছোট cluster
(2,1) 7 4.58 সবচেয়ে বেশি আলোচিত

(2,2) 12 6.00

চ্যানেল বণ্টন: মোট S টি duplex channel থাকলে প্রতি cell-এ k = S/N। N বাড়লে D/R বাড়ে (interference কমে) কিন্তু প্রতি cell-এ channel কমে (capacity কমে)। এটাই মূল trade-off। Cluster M বার পুনরাবৃত্তি হলে মোট capacity C = M × k × N = M × S।

৩.৩ Co-channel Interference ও SIR

প্রথম স্তরে 6টি co-channel cell পরিবেষ্টন করে। Path loss exponent n হলে:

SIR=IS​≈6(D/R)n​=6(3N)n/2​

  • GSM-এ সাধারণত SIR ≥ 9–12 dB, AMPS-এ ≈ 18 dB লাগে।

  • Adjacent channel interference: পাশের ফ্রিকোয়েন্সির leakage; guard band ও ভালো ফিল্টারে কমে।

সমাধানকৃত অঙ্ক ১ (SIR থেকে cluster size): প্রয়োজন 15 dB (= 31.62 গুণ), প্রথম স্তরে 6 interferer।

N n = 4-এ SIR n = 3-এ SIR
3 11.30 dB (ব্যর্থ) 6.53 dB (ব্যর্থ)
4 13.80 dB (ব্যর্থ) 8.41 dB (ব্যর্থ)
7 18.66 dB (পাস) 12.05 dB (ব্যর্থ)
9 20.85 dB 13.69 dB (ব্যর্থ)

উত্তর: n = 4-এ ন্যূনতম N = 7 (reuse factor 1/7); n = 3-এ ন্যূনতম N = 12 (reuse factor 1/12)। শিক্ষা: path loss exponent কম (খোলা এলাকা) হলে interference বেশি বহুদূরে পৌঁছায়, তাই বড় cluster লাগে।

৩.৪ Capacity বাড়ানোর কৌশল

Cell splitting: ব্যস্ত cell-কে ছোট cell-এ ভাগ। ব্যাসার্ধ অর্ধেক হলে ক্ষেত্রফল ¼ হয়, অর্থাৎ ওই জায়গায় cell সংখ্যা 4 গুণ। Path loss exponent n হলে প্রতি cell-এর transmit power কমাতে হয় প্রায় 2ⁿ গুণ; n = 4 হলে 1/16 (12 dB কম), যাতে SIR বজায় থাকে। অসুবিধা: নতুন সাইট ও handoff বেশি।

Sectoring: omni antenna-র বদলে directional antenna। Interferer 6 থেকে কমে 120° sector-এ 2, 60° sector-এ 1 হয়। উদাহরণ (n = 4, N = 7): omni SIR = 441/6 = 73.5 (18.66 dB); 120° sector = 441/2 = 220.5 (23.43 dB); 60° sector = 441/1 (26.44 dB)। এই SIR বাড়ার সুযোগে ছোট cluster ব্যবহার করে capacity বাড়ানো যায়। ক্ষতি: trunking efficiency কিছুটা কমে (channel ভাগ হয়ে যায়) ও handoff বাড়ে।

Microcell/Picocell/Femtocell: শহরের ঘন জায়গা, ভবনের ভেতরে ছোট কভারেজ। Repeater: কভারেজ বাড়ায়, capacity নয়। Frequency reuse-1 + ICIC: LTE/5G-তে সব cell একই ব্যান্ডে, interference সমন্বয় (ICIC/eICIC) ও scheduling দিয়ে সামলায়।

৩.৫ Trunking ও Grade of Service

অনেক ইউজার অল্প channel ভাগাভাগি করে, কারণ সবাই একসাথে কল করে না। Erlang-B (blocked calls cleared) দিয়ে নির্ধারণ হয় কতজন ইউজার কত blocking-এ সামলানো যায়।

সমাধানকৃত অঙ্ক ২: blocking 0.5%, প্রতি ইউজারের লোড 0.1 Erlang।

Channel সর্বোচ্চ লোড (Erlang) সমর্থিত ইউজার ইউজার/channel
5 1.132 ≈ 11 2.3
10 3.961 ≈ 39 4.0
20 11.092 ≈ 110 5.5
100 80.910 ≈ 809 8.1

শিক্ষা: channel বাড়ালে প্রতি channel-এ ইউজার বাড়ে। এটিই trunking efficiency; তাই বড় channel pool ছোট ছোট আলাদা pool-এর চেয়ে ভালো (sectoring-এ কেন সামান্য ক্ষতি, তার ব্যাখ্যাও এটাই)।

সমাধানকৃত অঙ্ক ৩ (spectrum থেকে channel): মোট 33 MHz, 25 kHz simplex channel → duplex channel প্রতিটি 50 kHz → 33 MHz / 50 kHz = 660 duplex channel। প্রতি cell-এ: N = 4 হলে 165, N = 7 হলে প্রায় 94, N = 12 হলে 55।

৩.৬ Handoff

কল চলাকালীন ইউজার cell ছাড়লে সংযোগ না কেটে নতুন cell-এ সরানো।

  • Handoff শুরুর মানদণ্ড: সংকেত শক্তি (RSSI/RSRP) একটি threshold-এর নিচে যাওয়া। threshold ও ন্যূনতম ব্যবহারযোগ্য সংকেতের পার্থক্য handoff margin Δ। Δ খুব ছোট হলে call drop (সময় থাকে না), খুব বড় হলে অযথা handoff।

  • Hysteresis: ping-pong (বারবার আসা-যাওয়া) এড়াতে।

  • Dwell time: একটি cell-এ ইউজার যতক্ষণ থাকে; দ্রুত ইউজারের dwell time কম, তাই microcell-এ দ্রুত গতির ইউজারকে umbrella macro cell-এ রাখা হয়।

  • Prioritizing handoff: নতুন কলের চেয়ে চলমান কল বেশি মূল্যবান, তাই কিছু guard channel শুধু handoff-এর জন্য সংরক্ষিত (নতুন কল ব্লক হওয়ার সম্ভাবনা বাড়ে, কিন্তু কল drop কমে)।

  • ধরন: Hard (break-before-make; GSM, LTE), Soft (make-before-break; CDMA/WCDMA), Softer (একই সাইটের দুই sector-এর মধ্যে)। MAHO (Mobile Assisted Handoff): ফোন নিজে প্রতিবেশী cell মেপে রিপোর্ট করে; GSM-এ ব্যবহৃত।

  • Intra-/Inter-BSC, Inter-MSC, Inter-RAT (যেমন 4G→3G) handoff।

৩.৭ GSM-এর বিস্তারিত (পরীক্ষায় প্রায়ই আসে)

স্থাপত্য:

উপ-ব্যবস্থা নোড কাজ
MS ME + SIM ফোন ও পরিচয় কার্ড
BSS BTS, BSC, TRAU রেডিও সংযোগ, channel ও handover ব্যবস্থাপনা
NSS MSC, GMSC, VLR, HLR, AuC, EIR সুইচিং, mobility, নিরাপত্তা
OSS OMC অপারেশন ও রক্ষণাবেক্ষণ

রেডিও প্যারামিটার: carrier ব্যবধান 200 kHz; প্রতি carrier-এ 8 time slot; এক slot = 576.9 µs (প্রায় 0.577 ms); এক TDMA frame = 8 slot = 4.615 ms; প্রতি slot-এ 156.25 bit; carrier-এর মোট bit rate = 270.833 kbps; modulation GMSK (BT = 0.3); GSM 900-এ 124টি ARFCN; frequency hopping প্রায় 217 hop/s; speech coding full-rate 13 kbps (RPE-LTP), ফলে 8 user প্রতি carrier-এ।

Timing advance: দূরের ফোনের সংকেত দেরিতে পৌঁছায়, তাই BTS ফোনকে আগে পাঠাতে বলে। 1 step = 1 bit period = 3.69 µs ≈ 550 m; সর্বোচ্চ 63 step ⇒ প্রায় 35 km সর্বোচ্চ cell radius (GSM-এ)।

Logical channel:

শ্রেণি চ্যানেল কাজ
Traffic TCH ভয়েস/ডেটা
Broadcast BCCH, FCCH, SCH cell তথ্য, ফ্রিকোয়েন্সি ও সময় সিঙ্ক
Common control PCH (paging), RACH (UL access), AGCH (access grant)
Dedicated control SDCCH, SACCH, FACCH সিগন্যালিং, ধীর/দ্রুত সংশ্লিষ্ট সিগন্যালিং

শনাক্তকারী: IMSI = MCC (3) + MNC (2–3) + MSIN; বাংলাদেশের MCC = 470; LAI = MCC + MNC + LAC; CGI = LAI + CI (Cell Identity)। (অপারেটর MNC: GP 01, Robi 02, Banglalink 03, Teletalk 04, এটি আমার স্মৃতি থেকে, নিশ্চিত হয়ে নিও।)

Location Area: একসাথে paging যাওয়া cell-গুচ্ছ। ফোন LA বদলালে Location Update; বড় LA-তে paging ভার বেশি, ছোট LA-তে update ভার বেশি।
