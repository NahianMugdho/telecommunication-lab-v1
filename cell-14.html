Topic 14: HLR, HSS ও Registry সিস্টেমHLR, HSS and Registry Systems

Theory • সহজ সারাংশ + বিস্তারিত নোটTheory • short note + detailed note

🧠 সংক্ষেপ নোটShort note

নেটওয়ার্ককে জানতে হয় প্রতিটি ইউজার কে, কী সেবা পাবে এবং এখন কোথায় আছে। এই তথ্য রাখে কিছু "রেজিস্ট্রি" ডাটাবেস: 2G/3G-তে HLR, VLR, AuC, EIR; 4G-তে HSS; 5G-তে UDM ও UDR।The network must know who each user is, what service they get and where they are now. A few "registry" databases hold this: HLR, VLR, AuC, EIR in 2G/3G; HSS in 4G; UDM and UDR in 5G.

  • HLR = স্থায়ী ডাটাবেস (IMSI, নম্বর, সেবা) + ইউজার এখন কোন VLR/MSC-তে আছে।HLR = permanent database (IMSI, number, services) + which VLR/MSC the user is in now.
  • VLR = অস্থায়ী ডাটাবেস, যে এলাকায় ইউজার আছে সেখানকার।VLR = temporary database for the area where the user is now.
  • AuC = গোপন key (Ki)। EIR = ডিভাইসের IMEI তালিকা।AuC = secret keys (Ki). EIR = list of device IMEIs.
  • EIR list: White = অনুমোদিত, Grey = নজরে, Black = ব্লক (চুরি)।EIR lists: White = approved, Grey = watched, Black = blocked (stolen).
  • HSS = HLR + AuC + IMS তথ্য। UDM/UDR = 5G সমতুল্য।HSS = HLR + AuC + IMS data. UDM/UDR = the 5G equivalent.
  • Incoming কল: GMSC → HLR (SRI) → VLR (MSRN) → কল রুট।Incoming call: GMSC → HLR (SRI) → VLR (MSRN) → route the call.

🧠 মনে রাখার কৌশল:Memory trick: HLR = "বাড়ির ঠিকানা" (স্থায়ী), VLR = "হোটেলের ঠিকানা" (অস্থায়ী)। ডাক HLR-এ গিয়ে জিজ্ঞেস করে "এখন কোন হোটেলে?"HLR = "home address" (permanent), VLR = "hotel address" (temporary). The post asks the home "which hotel is he in now?"

📖 বিস্তারিত নোটDetailed note

১৪.১ রেজিস্ট্রিগুলোর পরিচয়14.1 Meet the registers

🛵 উপমা:Analogy: একজন মানুষের বাড়ির ঠিকানা (HLR) সবসময় থাকে। সে ঢাকা থেকে সিলেটে গিয়ে হোটেলে উঠল (VLR)। বাড়িতে ফোন করলে বাড়ি বলে দেয় "সে এখন সিলেটের এই হোটেলে", তখন আসল কল সেখানে যায়।A person always has a home address (HLR). He travels from Dhaka to Sylhet and stays in a hotel (VLR). If you call his home, the home says "he is at this hotel in Sylhet now" and the real call goes there.

১৪.২ Location Update (ইউজার কোথায় তা জানানো)14.2 Location update (telling where the user is)
  1. ফোন নতুন Location Area-তে এসে নতুন VLR-কে জানায় (Location Update Request)।The phone enters a new Location Area and tells the new VLR (Location Update Request).
  2. নতুন VLR ইউজারের তথ্য ও triplet HLR থেকে আনে।The new VLR fetches the user's data and triplets from the HLR.
  3. HLR নিজের রেকর্ডে নতুন VLR/MSC ঠিকানা লিখে রাখে।The HLR writes the new VLR/MSC address in its record.
  4. HLR পুরোনো VLR-কে বলে ইউজারকে মুছে ফেলতে (Cancel Location)।The HLR tells the old VLR to delete the user (Cancel Location).

১৪.৪ EIR ও IMEI14.4 The EIR and the IMEI
  • IMEI: 15 digit; প্রথম 8 digit = TAC (ডিভাইসের ধরন ও কোম্পানি)।IMEI: 15 digits; the first 8 = TAC (device type and maker).
  • White list: অনুমোদিত। Black list: চুরি/হারানো, ব্লক। Grey list: সন্দেহজনক, পর্যবেক্ষণে।White list: approved. Black list: stolen/lost, blocked. Grey list: suspicious, under watch.

💡 HSS-এর বড় সুবিধা: একটি জায়গায় একই ইউজারের LTE ও IMS দুই ধরনের তথ্য থাকে, তাই আলাদা আলাদা ডাটাবেস মেলানোর ঝামেলা কমে।A big advantage of the HSS: one place holds both LTE and IMS data of a user, so there is less hassle keeping separate databases in step.
