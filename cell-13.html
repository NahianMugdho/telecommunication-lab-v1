Topic 13: Mobile User Data Management ও AuthenticationMobile User Data Management and Authentication

Theory • সহজ সারাংশ + বিস্তারিত নোটTheory • short note + detailed note

🧠 সংক্ষেপ নোটShort note

Authentication মানে নেটওয়ার্ক প্রমাণ চায় "তুমি কে?"। Ciphering মানে কথা ও ডেটা এমনভাবে গোপন করা যাতে আড়ি পাতলেও কেউ বুঝতে না পারে। মূল ধারণা: গোপন চাবি (Ki বা K) কখনো বাতাসে পাঠানো হয় না। শুধু একটি প্রশ্ন (RAND) যায় আর উত্তর (RES) ফেরে।Authentication means the network asks "who are you?". Ciphering hides calls and data so eavesdroppers cannot understand them. The key idea: the secret key (Ki or K) is never sent over the air. Only a question (RAND) goes and an answer (RES) returns.

  • GSM: RAND (128 bit) → SIM Ki দিয়ে SRES (32 bit) ও Kc (64 bit) বানায়। শুধু নেটওয়ার্ক ফোনকে যাচাই করে (একতরফা)।GSM: RAND (128 bits) → the SIM uses Ki to make SRES (32 bits) and Kc (64 bits). Only the network checks the phone (one-way).
  • UMTS AKA: AUTN-এর ভেতরের SQN ও MAC দিয়ে ফোনও নেটওয়ার্ককে যাচাই করে (দুই তরফা, replay ঠেকায়)।UMTS AKA: with the SQN and MAC inside AUTN the phone also checks the network (two-way, stops replay).
  • LTE: HSS মূল key K_ASME দেয়; তা থেকে NAS ও eNodeB-র key বানানো হয়। EEA1 = SNOW 3G, EEA2 = AES।LTE: the HSS gives the master key K_ASME; NAS and eNodeB keys come from it. EEA1 = SNOW 3G, EEA2 = AES.
  • 5G: IMSI-এর বদলে SUCI (SUPI encrypt করা) পাঠানো হয়, তাই IMSI-catcher কাজ করে না। দীর্ঘমেয়াদি key থাকে UDM/ARPF-এ।5G: sends the SUCI (an encrypted SUPI) instead of the IMSI, so IMSI-catchers fail. The long-term key lives in the UDM/ARPF.
  • গোপন key সরাসরি কখনো বাতাসে যায় না: Ki, K, K_ASME।The secret key never goes over the air directly: Ki, K, K_ASME.

🧠 মনে রাখার কৌশল:Memory trick: "প্রশ্ন যায়, উত্তর ফেরে, চাবি লুকানো থাকে।" RAND = প্রশ্ন, SRES/RES = উত্তর, Ki/K = লুকানো চাবি।"The question goes, the answer returns, the key stays hidden." RAND = question, SRES/RES = answer, Ki/K = hidden key.

🛵 উপমা:Analogy: ব্যাংকের লকারের মতো: তোমার কাছে আছে গোপন চাবি (Ki), ব্যাংকের কাছেও একটি কপি। ব্যাংক একটি এলোমেলো নম্বর (RAND) দেয়। তুমি চাবি দিয়ে তা থেকে উত্তর বানাও। ব্যাংকও একই হিসাব করে। উত্তর মিললে তুমি আসল। চাবি কাউকে দেখাতে হলো না।Like a bank locker: you have a secret key (Ki) and the bank has a copy. The bank gives a random number (RAND). You compute an answer from it with your key. The bank does the same. If the answers match, you are genuine. The key was never shown.

১৩.২ GSM Authentication13.2 GSM authentication
GSM-এর হিসাবGSM calculations
SRES = A3(Ki, RAND) (32 bit)
Kc = A8(Ki, RAND) (64 bit)
Cipher: A5/1 (stream), Kc + frame number → keystream
Ki ও RAND 128 bit। A3/A8 অপারেটরের algorithm (সাধারণত COMP128)। SIM ও AuC দুজনেই একই হিসাব করে।Ki and RAND are 128 bits. A3/A8 are the operator's algorithms (often COMP128). The SIM and the AuC compute the same thing.

⚠ ভুল ধারণা:Common mistake: GSM-এ শুধু নেটওয়ার্ক ফোনকে যাচাই করে। ফোন নেটওয়ার্ককে যাচাই করে না, তাই নকল টাওয়ার (fake BTS / IMSI catcher) বানানো সম্ভব। 3G-তে এটা ঠিক করা হয়েছে।In GSM only the network verifies the phone. The phone does not verify the network, so a fake tower (fake BTS / IMSI catcher) is possible. 3G fixed this.

১৩.৩ UMTS ও LTE: AKA13.3 UMTS and LTE: AKA
AUTN-এর গঠনStructure of AUTN
AUTN = (SQN ⊕ AK) ‖ AMF ‖ MAC
SQN = ক্রমিক নম্বর (পুরোনো বার্তা ফেরত পাঠানো ঠেকায়), AK = গোপন করার key, MAC = নেটওয়ার্কের স্বাক্ষর।SQN = sequence number (stops replay of old messages), AK = concealment key, MAC = the network's signature.

  • LTE: K থেকে CK, IK; তা থেকে HSS K_ASME বানায়। K_ASME → K_NASenc, K_NASint, K_eNB → K_RRC, K_UP।LTE: from K come CK and IK; from these the HSS makes K_ASME. K_ASME → K_NASenc, K_NASint, K_eNB → K_RRC, K_UP.
  • K কখনো USIM ও HSS/AuC ছাড়ে না।K never leaves the USIM and the HSS/AuC.
  • Algorithm: EEA1 = SNOW 3G, EEA2 = AES-128, EEA3 = ZUC। UMTS f8 = KASUMI। GSM A5/1 = 64-bit stream।Algorithms: EEA1 = SNOW 3G, EEA2 = AES-128, EEA3 = ZUC. UMTS f8 = KASUMI. GSM A5/1 = 64-bit stream.
১৩.৪ 5G Authentication13.4 5G authentication
  • SUPI = স্থায়ী পরিচয় (IMSI-র মতো)। SUCI = SUPI-কে home network-এর public key দিয়ে encrypt করা (ECIES)। বাতাসে শুধু SUCI যায়।SUPI = permanent identity (like the IMSI). SUCI = the SUPI encrypted with the home network public key (ECIES). Only the SUCI crosses the air.
  • AUSF authentication সার্ভার। SEAF (AMF-এ) visited নেটওয়ার্কের anchor। UDM/ARPF দীর্ঘমেয়াদি key ধরে রাখে।AUSF is the authentication server. The SEAF (in the AMF) is the visited-network anchor. The UDM/ARPF holds the long-term key.
  • পদ্ধতি: 5G-AKA বা EAP-AKA'।Methods: 5G-AKA or EAP-AKA'.
