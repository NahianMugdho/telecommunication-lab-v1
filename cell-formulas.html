টপিক 19 · ১৯.১৪ ধারা ও সংখ্যা সিরিজTopic 19 · 19.14 Series and number patterns

সমান্তর ধারা (AP)Arithmetic progression (AP)
aₙ = a + (n − 1)d, Sₙ = n/2 · [2a + (n − 1)d] = n(a + l)/2
1 + 2 + ... + n = n(n + 1)/2, 1² + 2² + ... + n² = n(n + 1)(2n + 1)/6
a = প্রথম পদ, d = সাধারণ অন্তর, l = শেষ পদ।a = first term, d = common difference, l = last term.
✍ 1 থেকে 100: 100 × 101/2 = 5050।1 to 100: 100 × 101/2 = 5050.
গুণোত্তর ধারা (GP)Geometric progression (GP)
aₙ = a · rⁿ⁻¹, Sₙ = a(rⁿ − 1)/(r − 1), S∞ = a/(1 − r) (|r| < 1)
✍ 2, 4, 8, ... 10টি পদ: 2(2¹⁰ − 1)/1 = 2046।2, 4, 8, ... 10 terms: 2(2¹⁰ − 1)/1 = 2046.
